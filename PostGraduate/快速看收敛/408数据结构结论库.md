# 408 数据结构 

不要所有的都想着推导尽量记忆一些可以高效利用大脑内存



## 0. 复杂度速判

- while(i<n) i=i*2 → **O(log₂n)**；通用"设 T 法"：设循环执行 T 次，用跳出条件反解 T
- 双重循环内层依赖外层（j<i）→ 1+2+…+n → **O(n²)**
- 双重循环别急着写 O(n²)：内层执行总量受全局条件限制时可能只有 O(n)（如 i 每轮倍增、i*i<n 型）
- 递归复杂度常用三个结果：T(n)=2T(n/2)+O(n)→O(nlogn)；T(n)=T(n/2)+O(1)→O(logn)；T(n)=2T(n/2)+O(1)→O(n)；T(n)=T(n−1)+O(1)→O(n)
- 空间复杂度只算**额外**空间；递归的空间 = 最大递归深度
- 常见增长速率排序：1 < log n < √n < n < nlogn < n² < n³ < 2ⁿ < n!

## 1. 线性表

- 顺序表：插入平均移动 **n/2**，删除平均 **(n−1)/2**（等概率）；**表尾插入/删除不移动任何元素**；随机存取 O(1) 是顺序表独有优势
- 顺序表按值查找：无序表平均 (n+1)/2 次；有序表可折半
- 链表：**头插法=逆序建表，尾插法=正序建表**；把一段结点逐个摘下头插=局部逆置
- 链表结点的**物理地址与逻辑顺序无关**——按内存地址推链接关系是陷阱
- 链表插入语句顺序铁律：**先让新结点接好两边，再改原有指针**（先断链数据就丢了）；删除结点 p 的后继：q=p->next; p->next=q->next; free(q)
- 单链表删除结点 p 本身（无前驱指针）：把后继值复制进 p 再删后继，O(1)
- 带尾指针 rear 的循环单链表：**删首元素不用遍历**（rear->next 是头）、**删尾要遍历**；带头结点的循环双链表判空：head->next==head
- 静态链表：用数组模拟链表，下标当指针，插删不移动元素但不能随机存取
- 快慢指针（一步/两步）：快到尾→慢在中点；固定间距 k：前指针先走 k 步，同步走到尾时后指针=倒数第 k 个
- 两升序表二路归并最坏比较次数 = **m+n−1**（最好 min(m,n)）
- 各操作选型：频繁按位访问→顺序表；频繁插删且已知位置→链表；既要随机存取又插删少→顺序表

## 2. 栈、队列、数组

### 栈
- n 个元素依次入栈的**出栈序列总数 = 卡特兰数 C(2n,n)/(n+1)**：n=3→5、n=4→14、n=5→42、n=6→132
- 出栈序列合法性判定：出现 k…i…j（i<j<k，即 k 先出、然后 i 在 j 前）即非法——**大数出栈后，仍在栈里的小数必须按从大到小出**
- 以第 k 个元素开头的出栈序列：此刻前 k−1 个元素都在栈中，**必须按 k−1,…,2,1 的相对顺序出**，后续元素可任意插入——计数用递推或小规模枚举
- 由出栈序列反推**最小栈容量**：模拟入出栈过程，栈内同时驻留元素的峰值
- 递归工作栈保存：**形参、局部变量、返回地址**——不保存全局变量、静态变量
- 共享栈（两端向中间长）：栈满条件 top1+1==top2；提高空间利用率
- 栈的应用清单：括号匹配、表达式求值与转换、递归消除、函数调用、DFS、进制转换、迷宫回溯
- 中缀转后缀（手工"加括号法"最快）：机器法用运算符栈——**新来的运算符优先级不高于栈顶就先弹栈顶**（左结合），左括号无条件进栈、只被右括号消
- 中缀转后缀过程中**运算符栈最大深度** = 未输出运算符（含左括号）同时驻留的峰值
- 后缀表达式求值：操作数栈，遇运算符弹两个数计算再压回；**后缀表达式无括号且运算次序唯一**
- 括号匹配所需栈容量 = 最大嵌套深度

### 队列
- 先来先服务/缓冲场景（打印缓冲、键盘缓冲、消息队列）一律**队列 FIFO**；BFS、层次遍历用队列
- 循环队列（牺牲一个单元法）：队满 **(rear+1)%m==front**、队空 **front==rear**；元素个数 **(rear−front+m)%m**
- 不牺牲单元的两种替代：加计数器 size；加标志位 tag（tag=1 且 front==rear 为满）
- rear 指向队尾元素**本身**还是**下一位置**，公式随之变——先看题目定义再套公式
- 双端队列：两端都可插删；**输入受限**=只一端能入、两端能出；**输出受限**=两端能入、只一端能出；判某序列可否得到→小规模直接枚举模拟，别找公式
- 车厢调度/多队列问题：所需最少队列数 = 序列中**递减断点**个数+1 的口径题，模拟分配

### 数组与特殊矩阵
- 二维数组行优先：LOC(i,j) = base + [(i−i₀)×列数 + (j−j₀)]×元素大小；列优先行列互换
- 对称矩阵下三角行优先压缩（下标从 1 起）：a(i,j)（i≥j）→ **k = i(i−1)/2 + j**；i<j 时先交换 i、j 再代入
- 上三角行优先（1 起）：k = (i−1)(2n−i+2)/2 + (j−i+1)——记不住就现场数"前 i−1 行共存了几个"
- 三对角（带状）矩阵（1 起，行优先）：**k = 2i+j−2**；反求行号 i≈⌈(k+1)/3⌉ 再验证
- 下标公式万能自检法：代入 a(1,1) 和 a(2,1) 验证
- 稀疏矩阵三元组表：**除三元组外还必须存总行数、总列数、非零元个数**；三元组表失去随机存取性
- 十字链表存稀疏矩阵：适合频繁插删/运算；每个非零元同时挂行链和列链

## 3. 树与二叉树

### 计数公式（提款机）
- **n₀ = n₂ + 1**（任何二叉树：叶子数 = 双分支结点数 + 1）——结点计数题先试它
- 任何树：**结点数 = 总度数 + 1 = 边数 + 1**；森林：**结点数 − 边数 = 树的棵数**
- 度为 m 的树 vs m 叉树：度为 m 的树**至少有一个**结点有 m 个孩子且至少 m+1 个结点；m 叉树可以全空
- 二叉树第 i 层最多 **2^(i−1)** 个；高 h 最多 **2^h−1** 个；度为 m 的树第 i 层最多 m^(i−1) 个
- **满二叉树**：n=2^h−1，叶子 2^(h−1)，编号 i 的父=⌊i/2⌋
- n 结点二叉树高度范围：**min ⌈log₂(n+1)⌉（完全形态），max n（单支）**
- **完全二叉树度 1 结点数只能是 0 或 1**（n 偶→1 个，n 奇→0 个）——高频陷阱
- 完全二叉树（1 起编号）：i 的孩子 2i、2i+1；父 ⌊i/2⌋；叶子数 **⌈n/2⌉**；最后一个非叶结点 ⌊n/2⌋；i>⌊n/2⌋ ⇔ i 是叶子
- n 结点完全二叉树高度 = **⌈log₂(n+1)⌉ 或 ⌊log₂n⌋+1**（两口径等价）
- 任意二叉树顺序存储（按完全二叉树编号）最坏需 **2^n−1** 个单元（单右支最费）
- 顺序存储合法性：位置 i 有结点 ⇒ 位置 ⌊i/2⌋ 必须有结点（根除外）
- **n 个结点二叉树形态数 = 卡特兰数 C(2n,n)/(n+1)**；先序序列固定时可能的中序序列数也是它
- 线索二叉树空链域恒为 **n+1** 个（2n 个指针域 − (n−1) 条边）
- 正则 k 叉树（度只有 0 和 k）：**n₀ = (k−1)·n_k + 1**；已知叶子数可反推高度上下界

### 遍历与还原
- **中序 + 前序/后序/层次中任一 → 唯一确定二叉树**；**前序+后序 → 不能唯一确定**（区分不出单左支/单右支）
- 序列相同特判四条：**前序=中序 ⇔ 无左孩子；中序=后序 ⇔ 无右孩子；前序=后序 ⇔ 只有根结点；前序=后序之逆 ⇔ 每层只有一个结点（任意单支树）**
- **祖先判定：前序中 a 在 b 前 且 后序中 a 在 b 后 ⇔ a 是 b 的祖先**
- 后序遍历中，任何结点都先于其全部祖先出现；前序中根最先、后序中根最后
- 中序相邻两结点 u、v（u 前 v 后）的结构关系：**u 无右子树 ⇒ v 是 u 的最近"右上"祖先；u 有右子树 ⇒ v 是 u 右子树的最左结点**（互为前驱后继关系判定）
- 非常规遍历（RNL、NRL 等）：一律转化成**镜像**的标准遍历再做
- 还原树的手法：前序定根 → 中序分左右 → 递归；已知树形求任何序列直接在图上走
- 前序序列 = 结点入栈次序，中序序列 = 出栈次序（形态数=卡特兰数的原因）
- 遍历的非递归：前/中序用栈；后序最难（需记录上次访问）；层次用队列
- 由层次序列+每结点度数可还原树（队列法）

### 线索二叉树
- 中序线索找**后继**：有右子树 → 右子树最左结点；无 → 右线索直接指向后继。找**前驱**对称
- 前序线索找后继容易（左孩子或右孩子或线索）、找**前驱难**（要父指针）；**后序线索找后继难**（要父指针）——所以"后序线索树遍历仍需栈或父指针"
- 中序线索化后：最左结点左线索为空（无前驱），最右结点右线索为空（无后继）
- 线索化的目的：不用栈/递归即可遍历，空间 O(1)

### 树、森林与二叉树转换
- 转换规则：**左孩子、右兄弟**；树根的兄弟（森林里其他树的根）挂到右链上
- **二叉树根无右孩子 ⇔ 原森林只有一棵树**
- **森林的叶结点数 = 对应二叉树中"无左孩子"的结点数**
- 树中结点的孩子数（度） = 二叉树中该结点"左孩子及左孩子的右链长度"
- 森林转二叉树的高度：后面的树整体挂在前一棵根的右链上——求最小高度时把高的树放前面
- 遍历对应关系：**树的先根 = 二叉树先序；树的后根 = 二叉树中序**；森林先序=二叉树先序、森林中序=二叉树中序
- 树的存储三法：双亲表示法（找父易找子难）、孩子表示法（找子易找父难）、**孩子兄弟表示法**（即转二叉树，两者兼顾）

### 哈夫曼树与编码
- n 个叶子的哈夫曼树：总结点 **2n−1**、**没有度为 1 的结点**、共合并 n−1 次
- WPL = Σ(叶子权×深度) = **所有非叶（分支）结点权值之和**——第二个口径算得快
- 父结点权 = 两孩子权之和；权越小离根越远；**同一组权形态可不同但 WPL 唯一**
- 权值最小的两个结点必互为兄弟且位于最深层
- k 叉哈夫曼：**(n−1)%(k−1)≠0 时先补 0 权虚叶结点**再合并
- **前缀码判定：任何一个编码都不是另一个编码的前缀**（树上=字符只出现在叶结点）
- 哈夫曼编码是最优前缀码；平均码长 = WPL ÷ 权值总和；总编码长 = WPL
- "与某字符同层/码长为 x 的字符数"类问题：按合并次序老实画树

## 4. 图

### 概念与计数
- 无向图：**边数 = 度数和 ÷ 2**；有向图：出度和 = 入度和 = 边数
- n 顶点无向图最多 **n(n−1)/2** 条边（完全图）；有向完全图 n(n−1) 条弧
- n 顶点无向图连通的**必要**条件：e ≥ n−1；**保证任意情况下必连通：e > C(n−1,2)，即至少 C(n−1,2)+1 条**
- n 顶点有向图强连通最少 **n** 条弧（构成一个环）
- **连通分量数 = DFS/BFS 被调用（重启）的次数**
- 生成树恒有 **n−1** 条边；边数 = n−1 且连通 ⇔ 树 ⇔ 无环且连通
- **无环无向图（森林）必存在度 ≤1 的顶点**
- 简单路径=顶点不重复的路径；回路存在判定：拓扑排序输出不完 ⇔ 有环（有向）；e≥n ⇒ 必有环（无向连通分量内）

### 存储结构
- 邻接矩阵：**第 i 行之和 = 出度，第 i 列之和 = 入度**（无向图行和=度）；有向图顶点的度 = 行非零数 + 列非零数
- **Aᵐ[i][j] = 从 i 到 j 长度为 m 的路径条数**（A 为邻接矩阵）
- **邻接矩阵是上三角（对角线全 0）⇒ 图无环 ⇒ 必存在拓扑序列**
- 邻接表：求出度 O(1+出边数)，**求入度必须扫全表 O(V+E)**；逆邻接表恰好相反
- 十字链表存**有向图**（出边入边都好找）；邻接多重表存**无向图**（一条边一个结点，删边方便）；求度=沿顶点的边链计数
- 复杂度总表：DFS/BFS/拓扑排序——邻接表 **O(V+E)**、邻接矩阵 **O(V²)**；稀疏图用邻接表省空间
- 同一图的邻接表表示不唯一（边表次序任意），邻接矩阵唯一

### 遍历
- BFS 用队列、DFS 用栈/递归；**BFS 可求无权（等权）图单源最短路径**
- DFS/BFS 序列合法性判定：逐位检查"下一个顶点是否与当前允许扩展的顶点邻接"
- DFS（或 BFS）序列可能的个数：逐步数每一步的可选邻接点，乘起来
- DFS 生成树高度 ≥ BFS 生成树高度
- **DFS 结束（出栈）次序的逆序 = 拓扑序列**（对 DAG）

### 最小生成树
- Prim：从点出发逐步吸点，O(V²)，**适合稠密图**；Kruskal：按权从小到大选不成环的边，O(ElogE)，**适合稀疏图**
- **各边权互不相等 ⇒ MST 唯一**；不论唯一与否，**MST 的权值总和唯一**
- MST 不唯一的可能来源：等权边；候选切分边等权
- 生成树/MST 是针对**连通无向图**的；非连通图得到生成森林

### 最短路径
- Dijkstra：**不能处理负权边**；每轮**永久确定**一个最近顶点（判"加入次序"题的依据）；dist 值只减不增；O(V²)
- Floyd：任意两点间最短路，**可负权、不可负环**，O(V³)，DP 思想
- 单源无权 → BFS；单源带正权 → Dijkstra；多源 → Floyd

### 拓扑排序与关键路径
- **有环 ⇔ 无拓扑序列**；拓扑排序实现：反复摘零入度点（用栈/队列均可）
- **拓扑序列唯一 ⇔ 每一步恰好只有一个零入度顶点**（注意：唯一拓扑序不代表是链，但链必唯一）
- 拓扑序列合法性检查：序列中排后面的顶点不得有边指向排前面的
- 拓扑序列个数：逐步枚举每步可选的零入度点相乘
- 逆拓扑排序：摘零**出**度点，或用 DFS 结束序
- AOV 网=顶点表示活动（拓扑排序用）；AOE 网=**边**表示活动、顶点是事件（关键路径用）
- AOE 结论组：**关键路径 = 源到汇的最长路径**；事件最早 ve=取入边最大、最迟 vl=取出边最小（逆推）；活动最早开始 e(i)=ve(弧尾)、最迟开始 l(i)=vl(弧头)−权；**关键活动 e=l（时间余量 d=l−e=0）**
- 缩短工期：只压缩**所有关键路径共有**的关键活动才有效；压过头会产生新的关键路径；**关键路径可能不止一条**
- 关键活动缩短到一定程度可能不再关键；加快非关键活动不影响工期

## 5. 查找

### 线性查找
- 顺序查找成功 ASL = **(n+1)/2**；失败 = n+1（无哨兵 n 次比较后越界判定，含哨兵 n+1）
- 哨兵的作用：省去每次循环的越界判断，比较次数省近一半的口径是"判断次数"
- **折半查找最多比较 ⌈log₂(n+1)⌉ 次**；成功 ASL ≈ log₂(n+1)−1
- 折半判定树：形态由 n 和 mid 取整方向唯一确定；**是平衡二叉树**；失败结点（外部结点）只出现在最下两层；左右子树结点数差 ≤1
- 折半查找路径合法性：路径必须满足"向左后遇到的都更小、向右后都更大"的单调夹逼
- **折半要求顺序存储（随机存取）+ 有序**——链表不能折半
- 分块查找（索引顺序查找）：块间有序、块内无序；**块数=块长=√n 时最优，ASL ≈ √n + 1**；ASL=块间查找+块内查找两段之和

### 树型查找
- BST 定义递归成立：**左子树全体 < 根 < 右子树全体**（是整棵子树，不只是孩子）
- **BST 中序遍历递增**——一切 BST 判定/输出题的钥匙
- BST 删除：叶直接删；单孩子接上；**双孩子用直接前驱（左子树最右）或直接后继（右子树最左）顶替**再删那个替身
- 同一组关键字不同插入顺序 → 形态不同、ASL 不同，但中序序列相同；**先删后插同一结点，形态可能改变**（非叶时）
- BST 查找路径（比较序列）合法性：向左拐后不能再出现比转折点大的值，反之亦然
- BST 最坏退化成链 O(n)——引出平衡化
- AVL：|左高−右高| ≤ 1；**高度 h 的最少结点数列：1, 2, 4, 7, 12, 20, 33, 54**（N_h=N_{h−1}+N_{h−2}+1）——反过来给结点数求最大高度
- AVL 插入调整只调**最小失衡子树**：LL→右单旋、RR→左单旋、LR→先左后右、RL→先右后左；插入+旋转后该子树高度恢复原值
- AVL 删除可能引起**沿途多次旋转**（插入最多一次调整）；删除后再插入同一关键字形态可能不同
- AVL 查找 O(logn)；n 结点 AVL 最大高度 O(logn)
- 红黑树五性质→两条推论：**最长路径 ≤ 2×最短路径；n 个内部结点高度 ≤ 2log₂(n+1)**；插入结点初始为红；根黑；红结点孩子必黑；各路径黑高相同
- 红黑树 vs AVL：红黑树平衡更宽松、插删旋转更少，适合频繁插删场景

### B 树 / B+ 树
- m 阶 B 树五条：①每结点 ≤ m 棵子树；②根（非叶）≥ 2 棵；③其余非叶 ≥ ⌈m/2⌉ 棵；④非根结点关键字数 **⌈m/2⌉−1 ~ m−1**（根 1~m−1）；⑤所有失败位置（空叶）在同一层
- 结点内"子树数 = 关键字数 + 1"永远成立
- 插入：结点关键字达到 m 个 → **分裂**：中间关键字上移父结点，左右各成一个结点；分裂可能逐层向上传播（树长高的唯一方式）
- 删除：非最下层先转化为删"直接前驱/后继"；关键字不足时**先向富裕兄弟借（经父旋转），借不到与兄弟合并**（树变矮的唯一方式）
- 数字题四板斧：**高 h 最少关键字**（按每结点最少配置算，如 3 阶高 h 最少 2^h−1 个）；**n 结点关键字上限**（每结点 m−1 个）；**关键字数固定求最多结点**（每结点放最少关键字）；**形态数**（小规模枚举插入分裂过程）
- B 树高度界：**log_m(n+1) ≤ h ≤ 1 + log_⌈m/2⌉((n+1)/2)**
- B 树查找是两级过程：结点间走指针（访盘）+ 结点内顺序/折半（内存中）；查找失败终止于最下层空指针
- B+ 树与 B 树的区别四条：①B+ 非叶结点**只索引不存记录**；②**全部关键字都在叶结点**且按序用链表串联（支持顺序扫描与范围查询）；③n 个关键字对应 **n 棵子树**（B 树是 n+1）；④B+ 支持两种查找方式（从根随机 / 沿叶链顺序）——数据库索引用 B+
- B+ 树查找即使命中也要走到叶结点（记录在叶）

### 散列表
- 装填因子 **α = 已存元素数 ÷ 表长**；**ASL 只与 α、散列函数、冲突处理方法有关，与 n 本身无关**
- 提高散列查找效率的途径：降低 α（扩表）、更均匀的散列函数、更好的冲突处理
- 常用散列函数：除留余数法 H(key)=key % p（p 取不大于表长的最大素数）、直接定址、数字分析、平方取中
- 冲突处理：开放定址族——**线性探测**（+1，聚集严重）、**平方探测**（±1²,±2²…，缓解聚集，但表长需为 4k+3 型素数才保证探到半表）、双散列、伪随机；**拉链法**（同义词挂链，适合频繁插删、α 可 >1）
- **堆积（聚集）直接影响的是 ASL**（探测变长），不影响存储利用率
- 开放定址法**删除只能打标记**（懒删除），物理删除会截断后续探测路径；拉链法可直接删
- ASL 双口径分开算：**成功 ASL = Σ(每个元素放入/找到时的比较次数) ÷ 元素个数；失败 ASL = Σ(从散列函数每个可能地址出发探测到"空"的次数) ÷ 散列函数值域大小**——失败的分母是值域大小（如 %13 就是 13），不是表长！
- 散列查找仍需比较关键字，ASL≠0；理想 O(1)，最坏退化 O(n)

## 6. 排序

### 判别口诀（识别题三板斧）
- **稳定四个：插入、冒泡、归并、基数**（口诀"插冒归基"）；不稳定：选择、希尔、快排、堆——判稳定性造反例：两个相等元素看是否可能换相对次序
- **每趟结束锁定至少一个最终位置：冒泡、简单选择、堆、快排（枢轴）**——判趟第一板斧
- 前 i 个（或某前缀）局部有序但**不保证是最终位置** = **插入排序**——判趟第二板斧
- **间隔 d 的各分组内部有序 = 希尔**，由一趟结果反推增量 d——判趟第三板斧
- 冒泡：每趟在序列**一端**新增一个就位的极值
- 快排一趟后判定：**枢轴左边全 ≤ 它、右边全 ≥ 它**；第 k 趟结束**至少 k** 个元素在最终位置（注意"至少"）

### 复杂度与次数总表
| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 直接插入 | O(n)（已有序） | O(n²) | O(n²) | O(1) | ✓ |
| 折半插入 | 比较 O(nlogn) 固定 | O(n²)（移动） | O(n²) | O(1) | ✓ |
| 冒泡 | O(n)（有序提前止） | O(n²) | O(n²) | O(1) | ✓ |
| 简单选择 | O(n²)（比较固定） | O(n²) | O(n²) | O(1) | ✗ |
| 希尔 | — | ≈O(n^1.3) | O(n²) | O(1) | ✗ |
| 快排 | O(nlogn) | O(nlogn) | O(n²)（基本有序/全等） | O(logn)~O(n) 栈 | ✗ |
| 堆排 | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | ✗ |
| 归并 | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | ✓ |
| 基数 | O(d(n+r)) | 同 | 同 | O(r) | ✓ |

- **简单选择比较次数固定 n(n−1)/2 与初始序列无关**；每趟至多交换 1 次——**"最坏情况下移动次数最少"选它**
- 直接插入已有序时比较 n−1、移动 0；**折半插入只减比较不减移动**，比较次数与初始序列基本无关
- **比较次数/趟数与初始序列无关的**：简单选择（比较）、折半插入（比较）、基数（全部）、归并（趟数）；**有关的**：快排（递归深度/趟数）、冒泡（可提前结束）
- 比较类排序理论下界 **⌈log₂(n!)⌉ ≈ nlog₂n**

### 各算法要点
- 快排：递归栈深最好 O(logn) 最坏 O(n)；最坏出现在基本有序或元素全等；优化=三数取中/随机枢轴；**内部排序平均性能最优**
- 堆：**建堆 O(n)**（自底向上从 ⌊n/2⌋ 号开始下滤）；**插入=上滤，每层比较 1 次**；**删堆顶=末元素补位+下滤，每层最多比较 2 次**（先比两孩子再比父）；判断数组是否堆：逐个验证 i 与 2i、2i+1
- 大顶堆适合升序排序（每次把最大换到末尾）；**求前 k 大/小（TOP-K）用堆最省**（容量 k 的反向堆）
- 归并：趟数 **⌈log₂n⌉**、每趟 O(n)；一趟归并两个长 m、n 段最多比较 m+n−1 次
- 希尔：分组插入思想；增量最后必须为 1；仅适合顺序存储
- 基数：**LSD 从最低位开始**，d 趟"分配+收集"，用 r 个队列；**多关键字排序（先按次关键字后按主关键字）= 基数思想**；全程无关键字比较
- 存储结构约束：**快排、希尔、堆、折半插入需要随机存取——不宜链表**；直插、简选、归并、基数可用链表
- 场景选型：基本有序或 n 小 → 直接插入；随机大规模 → 快排；要稳定的 O(nlogn) → 归并；只要最大/最小 k 个 → 堆；关键字位数少范围小 → 基数

### 外部排序
- 外部排序 = **多路归并**为核心；总时间 = 读写外存时间（大头）+ 内部排序 + 内部归并
- k 路归并趟数 **d = ⌈log_k r⌉**（r = 初始归并段数）：**增大 k 或减少 r 都能减少趟数（减少读写外存次数）**；初始段长度受内存工作区大小限制
- 置换-选择排序：工作区容量 m → 生成的初始段**平均长 2m、最短 m**（可远超内存限制），从而减少 r
- 最佳归并树 = 以段长为权的**哈夫曼树**（k 叉）；**(r−1)%(k−1) ≠ 0 时补长度为 0 的虚段**再构造；目的=总读写量最小
- 败者树：k 路归并中选最小元只需比较 **⌈log₂k⌉** 次（普通两两比要 k−1 次）；**树根记录的是冠军（最小值所在段号）**，内部结点记败者；增大 k 不增加选择开销的原因就是它

## 7. 串（KMP）

- 朴素匹配（BF）最坏 O(mn)；KMP **O(m+n)**；KMP 优势在主串**不回溯**
- next 数组（教材下标从 1 起口径）：next[j] = j 前面子串的**最长相等前后缀长度 + 1**；next[1]=0、next[2]=1
- 失配处理：j 回退到 next[j]，**i 不动**；j 退到 0 时 i、j 同时加 1
- nextval 修正：若 p[j] == p[next[j]]，则 nextval[j] = nextval[next[j]]（跳过注定失配的比较）
- 比较次数统计题：按 KMP 流程逐字符模拟，数"字符对比"发生的次数——回退本身不算比较
- 下标从 0 起的口径（王道/力扣风格）next 整体差 1——先看题目给的起始下标
