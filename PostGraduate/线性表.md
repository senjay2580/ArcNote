| 问题                                              | 举例（以循环队列为例）                                       |
| ------------------------------------------------- | ------------------------------------------------------------ |
| **1. 结构体怎么写？**                             | `int data[MaxSize]; int front, rear;`                        |
| **2. 判空/判满/求长的条件？**                     | 空 `front==rear`；满 `(rear+1)%MaxSize==front`；长 `(rear-front+MaxSize)%MaxSize` |
| **3. 各操作多少复杂度？**                         | 入队出队都 O(1)                                              |
| **4. 它和上一个结构比，牺牲了什么、换来了什么？** | 牺牲一个存储单元，换来"空"和"满"能区分                       |

**逻辑结构：数据之间的关系**

| 逻辑结构     | 关系                           | 例子                 |
| ------------ | ------------------------------ | -------------------- |
| **集合**     | 元素间没关系，只属于同一个集合 | 一个班级的学生       |
| **线性结构** | 一对一，有前后顺序             | 线性表、栈、队列、串 |
| **树形结构** | 一对多，有层次                 | 文件夹目录、二叉树   |
| **图状结构** | 多对多，任意相连               | 地铁线路图、社交网络 |



**物理结构：数据在内存中怎么存**

同一种逻辑结构，可以用不同的存储方式实现。

| 存储结构     | 特点                         | 例子             |
| ------------ | ---------------------------- | ---------------- |
| **顺序存储** | 内存连续存放，靠位置表示关系 | 数组实现的顺序表 |
| **链式存储** | 内存可不连续，靠指针表示关系 | 链表             |
| **索引存储** | 建索引表，通过索引找数据     | 数据库索引       |
| **散列存储** | 根据关键字直接算地址         | 哈希表           |

**大题 0 次**，所以**不要花时间练写代码**。把力气放在这四件事上：

1. **判空判满的条件怎么推**（不是背）
   - 顺序栈：`top` 指向栈顶元素还是下一个位置？两种约定 → 两套条件
   - 循环队列：为什么必须牺牲一个单元？（否则空和满都是 `front==rear`）
   - 共享栈：先看初值和入栈方式，画一次"刚好满"的图，条件就出来了
2. **出栈序列合法性**（选择题高频）——给入栈序列，判断某个出栈序列可不可能
3. **栈的三个应用**：括号匹配、中缀转后缀、后缀求值 —— **练手算，不练代码**
4. **递归 ↔ 栈的关系**：所有递归都能用栈改写；DFS 用栈、BFS 用队列，这个对应关系后面图那一章天天用

- 栈队列这一章的真正价值**不在它本身**，在于它是后面所有章节的**工具**：

  - 树的层序遍历 → **队列**
  - 树的非递归遍历 → **栈**
  - 图的 BFS → **队列**；图的 DFS → **栈/递归**
  - 拓扑排序 → **栈或队列**

  所以学栈队列时，重点是把「**数组 + front/rear 两个下标**」和「**数组 + top 一个下标**」这两个写法练熟——后面写树和图的代码，这两行是天天要用的。

  而且考场上**不需要写栈队列的实现**：直接写 `Stack S; InitStack(S); Push(S,x);` 并注明「S 是栈」即可，教材伪代码就是这么写的。
