## 一 规则与评分:先守住底线(基础)

1. **三问捆绑**(最大陷阱):思想、代码、复杂度必须是**同一个算法**,不匹配只能拿第一问约 30%。想不出最优解 → 三问统一写暴力。
2. **暴力分数账**:13 分题暴力约 10 分,升快排 11 分;15 分题暴力 9~11 分,快排 13 分;树题只用中序不管括号也有 9 分。**时间复杂度每降一档多拿 1~2 分**。
3. **"尽可能高效"两种口径**:默认=时间+空间;只写"时间上高效"=空间不计分;**时间考量>空间考量**(都会写时选时间低的);题干限定空间(2019 要求 O(1))才按空间来。
4. **答题规范速查**:只写核心函数(不写 include/main/输入输出);函数名用 `f`、参数名随题目、函数头加中文注释;语法不熟就写最简单 if-else,同样满分;`min/max/swap/abs` 直接用;`stack/queue` 可用;`list/map/set/sort` **禁用——排序必须自己写**;核心步骤写伪代码扣分;偶然笔误不扣分。

## 二 通用心法:6 个保底 + 5 个优化(基础→进阶)

**六种暴力解(保底)**
| 类型 | 套路 | 复杂度 |
|---|---|---|
| 循环+判断 | 双 for 内层 if | O(n²)/O(n³) |
| 辅助数组重排列 | 存起来→覆盖→拷回去 | O(n)/O(n) |
| 辅助数组计数/标记 | **触发器:题目给值域**(0≤aᵢ<n、\|data\|≤n) | O(n)/O(n) |
| 排序+处理 | 快排必须会默写 | O(nlogn) |
| 链表遍历+统计 | 一遍不够两遍(比一遍略扣分) | O(n) |
| 链表转数组 | 能用但低一档;**要求 O(1) 时禁用** | — |

**五个优化套路(拔分)**:无序→**排序+扫描/二分**;给值域→**计数数组/前缀和**;有序配对→**头尾双指针**;连续子数组+最长/最短→**滑动窗口**;"以 i 结尾的最大"→**DP**。

配套微技巧:求最小设上界 n+1、求最大设下界 INT_MIN(**含负数不能设 0**);枚举子数组增量维护 sum;双结果用引用参数带回;**双指针/滑窗必须能论证"不漏解",论证不了就写暴力**;复杂度别忘了递归栈 O(logn)。

**快排(全系列唯一指定必备,2~3 分钟默写)**
```c
void quick_sort(int A[], int low, int high) {
    if (low >= high) return;
    int i = low, j = high, temp = A[low];
    while (i < j) {
        while (i < j && A[j] >= temp) j--;   // 右找小
        A[i] = A[j];                          // 填左坑
        while (i < j && A[i] <= temp) i++;    // 左找大
        A[j] = A[i];                          // 填右坑
    }
    A[i] = temp;
    quick_sort(A, low, i - 1);
    quick_sort(A, i + 1, high);
}
```

## 四 链表真题

**工具箱**(带头结点):求表长(head->next 数起)、查/插/删(先定位第 n−1 个)、**三指针反转**(万能工具)、双指针两种距离(固定 k / 倍速找中点);判"相遇"比**地址**不比 data。

| 年份 | 题目 | 关键打法 | 最大坑 |
|---|---|---|---|
| 2009 | 倒数第 k | 快慢指针:快先走 k 步再同步 | 先走时每步判 NULL;k 超长返回 0 |
| 2012 | 公共后缀起点 | 长表先走 \|len1−len2\| 步再同步 | 比地址不比 data;返回结点指针 |
| 2015 | 绝对值去重 | **标答就是辅助数组** exists[n+1]+prev/curr 摘链 | 数组开 n+1;删除靠前驱 |
| 2019 | 重排 1,n,2,n−1 | 找中→逆置后半→交替插入,O(1) | 反转后中点置空;temp 防断链;**转数组只值两三分** |

三十天·链表(Day13–20):并集保序插入(p 不回退)→ 递增+递减归并(先原地逆置)→ 头尾配对(逆置后半段,算完恢复)→ 删所有重复(pre/p 看一步)→ 山峰形(严格≠,特判先行)→ 最接近中位数 k 个(逆置+归并取差值小者)→ 双向链表 Locate(先摘再插六步)→ 原地排序(考场写冒泡/递归归并更稳)。

## 五 树真题

**分治三板斧**:①定遍历(WPL 先序/表达式树中序/BST 靠中序递增);②分类(空/叶/非叶,不够再细分,2017 分到四类);③**有返回值必须用**(BST 左子树返假立刻短路)。

```c
// 2014 求WPL:叶=权×深,非叶=左+右
int WPL(BiTree t, int d) {
    if (!t) return 0;
    if (!t->left && !t->right) return t->weight * d;
    return WPL(t->left, d+1) + WPL(t->right, d+1);
}
```
心法:**不展开递归**,只想"本结点返回值与左右子树的关系";深度靠参数 d+1 传。

必背模板:先/中/后序递归(只差 visit 位置);**层次遍历分层**(先取 size 再 for size 次,会变着法考);非递归中序(栈)——BST 第 k 大=镜像"右根左";顺序存储孩子 **2i+1/2i+2**,−1 占位。

| 年份 | 题目 | 最大坑 |
|---|---|---|
| 2014 | WPL | 先写结构体定义;叶=左右全空;根算第 0 层 |
| 2017 | 表达式树→中缀 | 括号**跟运算符走**(根不加、deep>1 加);不管括号也有 9 分 |
| 2022 | 顺序存储 BST 判定 | **只比左右孩子≈零分**;必须中序严格递增(val 传指针)或上下界 |

三十天·树(Day21–26):最大值结点 → 引用带回 sum/n 求平均(强转 double)→ 两树等价(都空返 1、有一空返 0 提前返回)→ 单层和最大(分层模板)→ 路径和=k(**叶子单独判,并入空树会漏**)→ BST 第 k 大。

## 七 应用题专题

- **循环队列**:队满 front==(rear+1)%max,个数=(rear−front+max)%max;**2019 真题链式版:所有 +1 取模换成"沿 next 走"**,队满 rear->next==front。
- **KMP 手算**:next 前两位固定,后面="最长相等前后缀+1";**nextval:若相等则同化,不相等则保留**(例 'aabaac':next=012123,nextval=002003)。
- **BST 还原+ASL**:BST 中序=升序(挖隐含条件);ASL 成功=Σ层×个数/n;**失败 ASL 分母是空虚结点数(11),不是结点数(10)**——最大失分点。
- **AVL"数字万能法"**:找最小不平衡子树→沿插入路径取三点→**中位数做根**、其余一左一右→子树原样接回。LL/RR/RL/LR 一次到位;给字母或现成的树才用旋转法。
- **哈夫曼**:反复取最小两权(n 结点合 n−1 次,共 2n−1 结点);树不唯一、WPL 唯一;编码**左0右1(自命题查本校教材)**;2012 真题:"6 表 5 次合并"→哈夫曼,"最坏情况"→每次合并最坏比较 m+n−1,总次数=非叶权值和−合并次数。
- **关键路径快速法**:只列 ve 一行表,从前往后取 max,**取完划掉落选路径**,剩下的就是关键路径;题目要最早/最迟时间时 vl 行必须补全(得分点)。
- **最短路辨析(2009)**:"每次选最近邻"是贪心,局部最优≠全局最优→不可行,举两个反例;Dijkstra 比的是完整路径长度。
- **MST(2018 交叉题)**:"全网最省钱"=MST 不是最短路;等权边时 MST 不唯一要画全;可能跨科考 TTL(每过一个路由器减 1)。
- **散列表(2010)**:ASL 成功分母=记录数;**失败分母=模数(mod 7 除 7 不是表长 10)**,且只查余数范围内下标,探到第一个空位为止。
- **排序结论**:插入最好 n/稳定;快排一趟定 1 个;堆建 O(n) 调 O(logn);归并 O(n) 空间稳定;"堆、归并、快排针对大数据"。

## 八 考场执行清单

```
读题圈三点:①数据结构类型 ②值域/有序性/空间限制 ③"高效"修饰时间还是时空
→ 有值域用辅助数组;无序先想排序;找配对用双指针/二分;
  连续子数组用滑窗/前缀和;树用分治;图用求度+判断
→ 想不出优化:三问统一写暴力 + 背好的快排(至少六成,升级再拿 1~2 分)
→ 写完检查:三问同算法?初始化/边界(k=0、重复、负数、空表、单结点)?
  下标±1?复杂度与实现一致?
```

**高频易错 Top10**:①三问不捆绑;②计数数组忘清零;③求最值初值不当(含负数设 0);④滑窗忘登记首元素/j 从 1 起;⑤链表相遇比了 data;⑥孩子下标写成 2i/2i+1;⑦BST 只比左右孩子;⑧图行列反(行=出度)、判断缩进错;⑨链表删除断链、反转后忘置空;⑩快排丢 i<j 或不等号反向。
