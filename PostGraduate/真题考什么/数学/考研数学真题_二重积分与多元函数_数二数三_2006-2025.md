# 考研数学真题精选：二重积分 与 多元函数微分学（数学二 / 数学三，2006-2025）

> 选题口径：**二重积分**（计算、交换积分次序、极坐标、大小比较、和式极限化二重积分、反常二重积分）与**多元函数微分学**（偏导数、全微分、复合/隐函数求导、极值与条件极值、连续/可偏导/可微判定）。小题（选择/填空）与大题（解答）均收录，只含题干、不含解答。
> 来源：《考研数学真题【纯题版】(1987-2025)》扫描版逐页人工辨认抄录。个别混合考点题目标注了「(存疑)」；2022 年数学二试卷原版页面未印年份大标题，年份系按试卷排列顺序推断；该卷解答题未印单题分值处标「分值原卷未标」。

## 考情总结（基于本卷 2006–2025 约 150 道真题统计）

### 1. 分布与分值

| | 数学二 | 数学三 |
|---|---|---|
| 每年题量 | 3–5 道 | 2–4 道 |
| 每年分值 | 约 18–26 分 | 约 14–22 分 |
| 小题位置 | 选择第 4–6 题、填空第 10–14 题 | 选择第 2–4 题、填空第 10–14 题 |
| 大题位置 | 解答第 17–21 题 | 解答第 16–19 题 |

两个考点合计约占试卷 15%，**年年必考**：二重积分大题（10–12 分）数二 20 年几乎不缺席（仅 2020 只考填空），数三仅 2019 缺席；多元微分几乎每年小题+大题都有。数二数三大量共用原题（2013–2017、2022 多道双卷同题），材料可互通。

### 2. 二重积分考什么

- **小题三大套路（占小题 90%）**：① 交换次序 / 直角⇄极坐标互化（最高频，陷阱在雅可比因子 $r$ 与反解上下限）；② 对称性/定号比大小；③ 被积函数沿原次序积不出（$\frac{\mathrm{e}^{x^2}}{x}$、$\frac{\tan x}{x}$、$\sqrt{x^3+1}$、$\sin\frac{x}{y}$ 型），逼你先交换次序。
- **大题模板按频率**：极坐标+偏心圆（$x^2+y^2=2y\Rightarrow r=2\sin\theta$）＞对称性拆分（先扔奇函数）＞分块积分（$\max$、绝对值、分段）＞特殊边界（摆线、双纽线、广义换元）＞把 $\iint f$ 设为常数解方程＞反常二重积分（数三专属）。

### 3. 多元微分考什么

- **小题**：① 连续/偏导存在/可微判定（近 5 年明显加密，分段函数反例型）；② 隐函数求 $\frac{\partial z}{\partial x}$、$\mathrm{d}z\big|_{点}$——**填空最高频送分题**，近年升级为二阶。
- **大题三大模板**：① 求极值（最高频；变体：隐函数极值、先由偏导条件还原 $f$ 再求极值——近年最爱缝合款）；② 抽象复合函数二阶偏导、代入方程反解 ODE（**最难最区分人**）；③ 条件极值 Lagrange / 最值应用（数三常包装成利润最大化、弹性等经济应用）。

### 4. 难度分层

- **送分层**：隐函数偏导/全微分填空、常规交换次序、奇函数对称抵消。
- **主力层（约 70% 大题）**：极坐标计算、普通二元极值、一阶抽象复合求导——套路完全固定。
- **区分层**：抽象二阶偏导+变换化简方程、还原函数+极值缝合题、特殊边界积分、可微性判定难题。
- 趋势：计算量加大、缝合增多，但套路池 20 年基本没变，无超纲怪题。

### 5. 重点掌握清单（按优先级）

1. 交换积分次序 + 极坐标互化，正反都要秒；
2. 极坐标算二重积分（偏心圆 $r=2\sin\theta$ 型）；
3. 对称性三板斧：奇偶抵消、轮换对称、$x\leftrightarrow y$ 互换；
4. 隐函数偏导/全微分公式（含二阶）；
5. 二元极值完整流程：驻点 → $AC-B^2$ 判别 → 约束（Lagrange）；
6. 抽象复合二阶偏导的规范书写（$f''_{11},f''_{12}$）；
7. 由 $\mathrm{d}f=P\mathrm{d}x+Q\mathrm{d}y$ 还原原函数（缝合题入口）；
8. 连续/偏导/可微判定的反例库；
9. 数三另加：反常二重积分、经济应用。
