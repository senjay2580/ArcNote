# 408 统考核心笔记：知识框架、大题母题与学习闭环

> 分值：数据结构 45 分、计算机组成原理 45 分、操作系统 35 分、计算机网络 25 分。  
> 使用方法：先闭卷讲主线，再按固定步骤做题；本笔记用于搭框架、查缺口，不代替真题训练。

## 一、全科总览

| 科目 | 核心问题 | 大题重点 |
|---|---|---|
| 数据结构 | 数据如何组织，算法如何高效处理 | 链表、树、图、查找、排序算法 |
| 计算机组成原理 | 一条指令如何被硬件执行 | Cache、指令系统、数据通路、C 与汇编、流水线 |
| 操作系统 | 多个进程如何共享 CPU、内存、文件和设备 | PV、分页与缺页、文件系统、调度 |
| 计算机网络 | 数据如何跨网络到达目标进程 | IP 与路由、TCP、以太网与 ARP |

四科可串成一条系统主线：

```text
程序使用数据结构组织数据
→ 编译为机器指令，由 CPU 取指、译码、执行
→ OS 调度进程并管理虚拟内存、文件和 I/O
→ Cache/主存提供指令和数据，DMA/中断协助设备传输
→ 网络协议逐层封装，经交换机和路由器转发
→ TCP/UDP 按端口把数据交给目标进程
```

## 二、数据结构（45 分）

### 1. 算法分析

- 数据结构三要素：逻辑结构、存储结构、数据运算。
- 时间复杂度：关注基本操作执行次数，掌握循环、递归、递推式和主定理分析。
- 空间复杂度：重点判断辅助空间是否随输入规模增长。
- 做题先确认最坏、最好还是平均情况，不能只看代码层数。

### 2. 线性表

- 顺序表：支持随机访问；插入、删除通常需要移动元素。
- 链表：不支持随机访问；已知结点位置时插入、删除方便。掌握单链表、双链表、循环链表和静态链表。
- 必会算法：逆置、删除重复元素、合并有序表、找公共结点、中间结点、倒数第 `k` 个结点。

链表题固定检查：

```text
是否有头结点 → 是否可能为空 → 指针是否先保存再修改
→ 首尾结点是否单独处理 → 时间/空间复杂度是否符合要求
```

### 3. 栈、队列、数组与串

- 栈：括号匹配、中缀转后缀、表达式求值、递归模拟、共享栈。
- 队列：循环队列判空判满、链式队列、双端队列。
- 合法出栈序列数量与卡特兰数有关；题目也常直接判断某序列能否产生。
- 特殊矩阵：对称、三角、三对角和稀疏矩阵的压缩存储与下标换算。
- 串：掌握 KMP 的 `next` / `nextval` 手算与匹配过程。

### 4. 树与二叉树

- 性质：结点数、叶子数、高度以及度之间的关系；掌握顺序存储和链式存储。
- 遍历：先序、中序、后序、层序；由“先序+中序”或“后序+中序”还原二叉树。
- 线索二叉树：线索化过程及前驱、后继查找。
- 树、森林与二叉树：左孩子右兄弟表示及相互转换。
- 哈夫曼树：构造、带权路径长度 `WPL`、哈夫曼编码。
- 并查集：按秩合并、路径压缩及连通性判断。
- 高频算法：树高、宽度、结点数、完全性判断、非递归遍历、叶子结点链接。

树算法题的递归骨架：

```text
明确函数返回什么
→ 写空树边界
→ 分别处理左右子树
→ 合并左右结果
```

### 5. 图

- 存储：邻接矩阵适合稠密图，邻接表适合稀疏图；了解十字链表和邻接多重表的适用对象。
- 遍历：DFS 用递归/栈，BFS 用队列；非连通图需从每个未访问顶点重新开始。
- 最小生成树：Prim 偏向稠密图，Kruskal 偏向稀疏图。
- 最短路径：Dijkstra 求非负权单源最短路；Floyd 求多源最短路。
- 拓扑排序用于 AOV 网；关键路径用于 AOE 网，核心是 `ve/vl/e/l`。
- 高频算法：邻接表上的 DFS/BFS、连通性判断、是否为树。

### 6. 查找

- 折半查找：适用于有序顺序表；会画判定树并计算成功/失败 ASL。
- 分块查找：索引表有序、块内可无序，查找过程分为定位块和块内查找。
- 散列表：掌握装填因子、开放定址、拉链法和 ASL。
- B 树：所有叶结点在同层，掌握插入分裂、删除调整和高度估算。
- B+ 树：内部结点只作索引，数据集中在叶层，叶结点通常有顺序链。
- 红黑树：掌握根黑、红结点孩子黑、各路径黑高相同等基本性质。

### 7. 排序

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 |
|---|---:|---:|---:|---:|
| 直接插入 | `O(n²)` | `O(n²)` | `O(1)` | 稳定 |
| 希尔 | 与增量有关 | 通常按题设分析 | `O(1)` | 不稳定 |
| 冒泡 | `O(n²)` | `O(n²)` | `O(1)` | 稳定 |
| 快速排序 | `O(n log n)` | `O(n²)` | 平均 `O(log n)` | 不稳定 |
| 简单选择 | `O(n²)` | `O(n²)` | `O(1)` | 不稳定 |
| 堆排序 | `O(n log n)` | `O(n log n)` | `O(1)` | 不稳定 |
| 归并排序 | `O(n log n)` | `O(n log n)` | `O(n)` | 稳定 |
| 基数排序 | `O(d(n+r))` | 同左 | `O(n+r)` | 稳定 |

高频题：识别排序中间状态、写第 `k` 趟结果、建堆与调整、快速划分、二路归并。

### 8. 数据结构大题母题

| 母题 | 固定思路 |
|---|---|
| 线性表算法 | 明确存储结构和边界，再设计一次或两次扫描 |
| 二叉树算法 | 定义递归含义，写空树边界，合并左右结果 |
| 图算法 | 选邻接矩阵/表，维护 `visited`，处理非连通情况 |
| 查找与树形索引 | 逐步模拟比较、分裂、合并或冲突处理 |
| 排序过程 | 按算法不变量逐趟写序列，不能凭最终结果反推 |

## 三、计算机组成原理（45 分）

### 1. 整体执行主线

```text
C 语句 → 机器指令 → PC 取指 → 译码与寻址
→ MMU/TLB 地址转换 → Cache/主存取数
→ ALU 运算 → 写回结果 → 中断或继续执行
```

做计组大题始终追踪：数据在哪里、地址怎样得到、经过哪些部件、由哪些控制信号驱动、共花多少时间。

### 2. 系统概述与性能

- 冯·诺依曼结构：存储程序、指令和数据同等存放，按地址访问，指令顺序执行为主。
- 三种字长：机器字长反映一次整数运算能力；指令字长是一条指令的位数；存储字长是存储单元位数。
- 性能主线：`CPU 时间 = 指令数 × CPI × 时钟周期`。
- `MIPS` 适合比较同一指令系统下的整数指令执行速度；`MFLOPS` 衡量浮点运算速度，均不能脱离工作负载和体系结构孤立比较。
- Amdahl 定律：整体加速比受“可加速部分占比”限制，局部无限加速也不能消除未改进部分的时间。

### 3. 数据表示与运算

- 进制转换：二、八、十、十六进制之间转换，注意小数部分和有限精度。
- 掌握原码、反码、补码、移码的范围和转换。
- 位宽扩大：无符号数零扩展，有符号补码通常符号扩展；位宽缩小会截断。
- 强制类型转换：同位宽时通常保持位模式，按新类型重新解释。
- `OF` 判断有符号溢出，`CF` 判断无符号进位/借位，不能混用。
- 定点乘除：掌握 Booth 乘法、恢复余数/不恢复余数除法的基本过程及位宽、符号和溢出判断。
- IEEE 754：符号位、阶码、尾数；浮点运算按“对阶→尾数运算→规格化→舍入→判溢出”。
- 电路基础：全加器产生本位和与进位；串行进位简单但慢，并行进位以更多硬件换速度；ALU 完成算术和逻辑运算。

固定检查顺序：

```text
确定位宽和类型 → 写位模式 → 扩展/截断 → 运算
→ 分别按有符号/无符号解释 → 判断 OF/CF
```

### 4. 存储系统与 Cache

- 存储层次：寄存器 → Cache → 主存 → 外存；速度下降、容量上升。
- 主存：SRAM、DRAM 刷新、ROM、Flash；位扩展、字扩展、字位同时扩展；多体交叉存储。
- Cache 映射：直接映射、全相联、组相联；替换常见 LRU/FIFO；写策略注意写回/全写和写分配/非写分配。

Cache 地址题：

```text
Cache 行数 = 数据区容量 / 块大小
组数 = Cache 行数 / 相联度
块内偏移位 = log₂(块大小)
组索引位 = log₂(组数)
Tag 位 = 地址总位数 - 组索引位 - 块内偏移位
平均访问时间 = 命中时间 + 缺失率 × 缺失损失（以题设模型为准）
```

数组访问先列：起始地址、元素大小、每块元素数、访问顺序、读写次数、初始状态和写策略。一个元素跨块时可能产生两次块访问。

### 5. TLB、页表、Cache 联合访问

```text
CPU 产生虚拟地址 VA
→ 用虚页号查 TLB
→ 未命中则查页表
→ 页表项无效：缺页异常，由 OS 调页
→ 页表项有效：得到物理地址 PA
→ 用 PA 访问 Cache
→ Cache 缺失：访问主存
```

| 事件 | 含义 | 处理者 |
|---|---|---|
| TLB 未命中 | 地址映射不在 TLB | 硬件或 OS 查页表 |
| Cache 缺失 | 数据块不在 Cache | 硬件取主存块 |
| 缺页 | 页面不在主存 | OS 调页 |

三者不能混为一谈。

### 6. 指令系统、汇编与寻址

- 指令格式：操作码、地址码、定长/变长指令。
- 常见寻址：立即、直接、间接、寄存器、寄存器间接、基址、变址、相对、堆栈。
- 典型有效地址：基址 `EA=(BR)+A`，变址 `EA=(IX)+A`，相对 `EA=(PC)+A`。
- 寻址方式先得到虚拟有效地址，随后 MMU 再做虚拟—物理地址转换。
- C 与汇编题追踪：类型和位宽、寄存器/栈位置、寻址方式、条件码、函数栈帧、大小端、实际访存地址。
- CISC 指令多而复杂、格式不规整；RISC 指令少而规整，强调寄存器操作和流水线。二者是设计取向，不与某一种控制器绝对绑定。

### 7. CPU 数据通路与控制器

```text
机器指令 → 取指/间址/执行/中断阶段
→ 每阶段分成节拍 → 每节拍完成可并行微操作
→ 控制信号驱动寄存器、总线、ALU 和存储器
```

数据通路题固定步骤：

1. 根据指令语义找源操作数和目的位置。
2. 沿图确定寄存器、总线、ALU、存储器的数据路径。
3. 按节拍写微操作。
4. 写寄存器写使能、门控、`ALUop`、`MemRead/MemWrite` 等信号。
5. 检查同一节拍的总线冲突和先后依赖。

硬布线控制速度快但修改困难；微程序控制规整、易扩展但通常较慢。

微程序题还要区分水平型/垂直型微指令、控制字段编码方式，以及微地址由顺序地址、转移条件或机器指令操作码形成。

### 8. 指令流水线

```text
时钟周期 = 最慢流水段时间 + 锁存开销
n 条指令理想时间 = (流水段数 + n - 1) × 时钟周期
吞吐率 = 指令数 / 总时间
加速比 = 非流水时间 / 流水时间
```

| 冒险 | 原因 | 常见处理 |
|---|---|---|
| 结构冒险 | 争用硬件资源 | 增加资源、停顿 |
| 数据冒险 | 后续指令依赖前面结果 | 转发、停顿、调度 |
| 控制冒险 | 分支结果未确定 | 预测、冲刷、延迟槽 |

必须画“指令 × 周期”时空表，逐周期判断转发、停顿和分支影响。

扩展结构：超标量在一个周期发射多条指令，超流水提高流水级频率，动态调度在运行时调整指令执行次序；SIMD 对多份数据执行同一指令，MIMD 的处理单元可执行不同指令流。

### 9. 总线、I/O、中断与 DMA

- 总线仲裁：链式查询简单但优先级固定，计数器查询较灵活，独立请求速度快但线路多；掌握同步、异步、半同步、分离式定时和带宽计算。
- I/O 接口：区分控制、状态和数据端口；统一编址把端口视为内存地址，独立编址使用专门 I/O 指令。
- 程序查询：CPU 反复检查设备状态。
- 中断：设备完成后通知 CPU；CPU 保存断点和现场，按中断向量进入处理程序。
- DMA：CPU 负责初始化和完成处理，数据块主要在设备与主存间传输。
- 通道和 I/O 处理机可进一步独立组织复杂 I/O 操作，减少 CPU 对具体设备过程的干预。
- 高频计算：中断响应时间、DMA 总线请求次数、周期挪用、传送时间。

### 10. 计组大题优先级

1. Cache 地址划分、数组访问与命中率。
2. 指令格式、寻址方式、C 与汇编。
3. CPU 数据通路、微操作和控制信号。
4. TLB—页表—Cache 综合。
5. 补码/浮点、流水线。
6. 中断、DMA、总线。

## 四、操作系统（35 分）

### 1. 整体主线

```text
创建进程 → 调度 CPU → 同步互斥
→ 虚拟地址经页表映射 → 缺页时调页
→ 系统调用访问文件 → 目录/inode 找到磁盘块
→ 驱动和控制器启动 I/O → DMA 传输 → 中断唤醒进程
```

### 2. 基础机制

- 四个基本特征：并发、共享、虚拟、异步；并发与共享相互依存。
- 用户态只能执行非特权指令；核心态可执行特权指令并访问内核资源。
- 中断来自外部事件，异常通常由当前指令内部引起；系统调用通过陷入进入内核。
- 大内核把主要服务置于内核，调用高效但耦合较强；微内核只保留核心机制，隔离性好但通信开销较大。

### 3. 进程、线程与调度

- 状态转换：就绪→运行靠调度；运行→阻塞是等待事件；阻塞→就绪是事件完成，不能直接到运行。
- 上下文切换：保存当前进程的 PC、寄存器、PSW 等到 PCB，再恢复下一进程现场。
- 线程实现：用户级、内核级、混合；是否进入内核取决于实现和题设。
- 管程把共享数据及其操作封装在一起，并用条件变量组织等待与唤醒；题目若区分 Hoare/Mesa 语义，以题设的唤醒后执行规则为准。
- 调度：FCFS、SJF/SRTN、优先级、RR、多级反馈队列、HRRN。

调度题固定步骤：

```text
列到达时刻和服务时间 → 明确抢占规则/时间片/优先数含义
→ 画甘特图 → 标记抢占、阻塞、唤醒和完成
→ 计算响应、等待、周转、带权周转时间
```

时钟中断次数、调度次数、上下文切换次数不是同一个量。

### 4. PV 同步互斥

| 关系 | 含义 | 常用初值 |
|---|---|---:|
| 互斥 | 同时只允许一个执行流进入临界区 | `mutex=1` |
| 前驱同步 | B 必须等待 A 完成 | `sAB=0` |
| 资源计数 | 共有 `n` 个同类资源 | `resource=n` |

PV 题固定步骤：

1. 找出执行主体。
2. 找共享资源和临界区。
3. 画前驱关系。
4. 找容量和并发数量限制。
5. 设信号量，再写 `wait/P` 与 `signal/V`。
6. 检查先后顺序、互斥、资源计数和循环等待。

高频变式：前驱图、生产者—消费者、读者—写者、哲学家进餐、有限缓冲区、多类资源。

### 5. 死锁

- 四个必要条件：互斥、请求并保持、不剥夺、循环等待。
- 处理：预防、避免、检测与解除。
- 资源分配图可用于分析等待关系；化简后仍有进程不能消去时，再结合资源实例数判断死锁。
- 银行家算法：`Need = Max - Allocation`，从 `Work = Available` 开始不断找 `Need ≤ Work` 的进程，假设其完成后令 `Work += Allocation`。
- 有安全序列则状态安全；不安全表示未来可能死锁，不等于已经死锁。

### 6. 内存管理与分页

- 连续分配：首次/最佳/最坏适应，注意内外碎片。
- 分页：虚拟地址拆成虚页号 `VPN` 和页内偏移，查页表得到页框号 `PFN`；页内偏移不变。
- 分段按逻辑模块划分，地址为段号+段内偏移；段页式先分段再分页，兼顾逻辑共享与离散分配。
- 多级页表：按各级索引逐级定位页表项，常考页表项地址、物理地址和页表占用页框数。
- TLB 是页表项的高速缓存；TLB 未命中不等于缺页。

请求分页流程：

```text
访问虚拟页 → 页表项显示不在内存 → 缺页异常
→ 检查合法性 → 找空闲页框
→ 必要时淘汰页面并写回脏页
→ 从外存调入目标页 → 更新页表/TLB → 重启指令
```

| 算法 | 淘汰依据 | 特点 |
|---|---|---|
| OPT | 未来最晚再访问 | 理论最优 |
| FIFO | 最早进入内存 | 可能出现 Belady 异常 |
| LRU | 最久未访问 | 利用过去预测未来 |
| CLOCK | 环形扫描访问位 | LRU 的近似实现 |

改进 CLOCK 同时参考访问位和修改位，优先淘汰未访问且未修改的页面。

缺页不一定置换：有空闲页框时只缺页、不淘汰。分配策略决定进程可占多少页框，置换策略决定淘汰谁。工作集刻画一段时间内活跃页面；页框过少会使缺页频繁并产生抖动。

页框管理需区分固定分配/可变分配和局部置换/全局置换：前者决定驻留集能否变化，后者决定牺牲页能否来自其他进程。内存映射文件把文件区间映射到虚拟地址，首次访问可通过缺页从文件调入。

### 7. 文件与目录

```text
文件名 → 逐级查目录项 → 得到 FCB/inode
→ 根据地址项定位逻辑块对应的磁盘块 → 执行 I/O
```

- 目录项保存文件名和 inode 号/FCB 位置；inode 保存文件元数据和数据块地址，不保存文件名。
- 文件逻辑结构分为无结构字节流和有结构记录文件，记录文件常见顺序、索引和索引顺序组织。
- 目录可采用单级、两级、树形和无环图结构；无环图便于共享，但必须管理引用关系。
- 打开文件：路径查找、权限检查、建立系统打开文件表项和进程文件描述符；不是把整个文件读入内存。
- 硬链接共享 inode；删除目录项后，链接计数为 0 才真正回收 inode 和数据块。
- 文件保护包括口令、加密和访问控制表；软链接保存目标路径，目标删除后可能悬空。
- 物理分配：连续分配快但扩展困难；链接分配易扩展但随机访问慢，FAT 把链接指针集中在表中；索引分配支持随机访问但有索引开销。

多级索引通式：设盘块大小为 `B`、地址项大小为 `A`，则每个索引块含 `N=B/A` 个地址项。

```text
d 个直接地址覆盖 dB
一个一级间接地址覆盖 NB
一个二级间接地址覆盖 N²B
一个三级间接地址覆盖 N³B
```

访问次数要根据 inode、索引块、数据块是否已在内存逐层计算，不能机械套层数。

空闲空间管理：空闲表、空闲链表、位图、成组链接。位图题先确认 0/1 含义、每字位数和盘块编号起点。

RAID 通过条带、镜像和校验在性能、容量与容错之间折中；具体级别的可用容量和容错盘数按题设结构计算。

### 8. I/O 与磁盘

```text
进程调用 read → 陷入内核 → 文件系统定位块
→ 检查页缓存/缓冲区 → 驱动设置控制器
→ DMA/控制器传输 → 完成中断 → 唤醒进程进入就绪态
```

- 设备独立性软件提供统一接口、命名、保护和缓冲。
- 驱动程序把通用请求翻译为设备命令。
- SPOOLing 用磁盘模拟独占设备，形成输入井/输出井。
- 缓冲用于缓和 CPU 与设备的速度、粒度差异；掌握单缓冲、双缓冲、循环缓冲和缓冲池的并行时间计算。
- 设备分配与回收要结合独占/共享/虚拟设备、设备控制表和阻塞唤醒过程判断。
- 磁盘调度：FCFS、SSTF、SCAN、C-SCAN、LOOK、C-LOOK；先画磁道数轴、当前位置和移动方向。
- 磁盘访问时间由寻道、旋转延迟和数据传输时间组成；题目若给平均值，要确认是否已包含控制器或排队开销。

### 9. 操作系统大题优先级

1. PV 同步互斥。
2. 分页地址转换、缺页与页面置换。
3. 目录、inode、多级索引和访盘次数。
4. 调度和进程状态。
5. 死锁、I/O、磁盘调度。

## 五、计算机网络（25 分）

### 1. 整体通信主线

```text
DNS 得到服务器 IP → 创建套接字 → TCP 建连
→ IP 选择路由 → ARP 获取下一跳 MAC
→ 以太网封装并经交换机转发
→ 路由器逐跳查表并重新封装帧
→ 接收端解封装 → TCP/UDP 按端口交给应用进程
```

计网大题重点追踪三件事：时延怎样累计、地址怎样变化、各类表和 TCP 状态怎样更新。

### 2. 体系结构

- OSI 七层用于理论分层，TCP/IP 常按网络接口层、网际层、传输层、应用层组织；408 常用五层模型讲解。
- 各层 PDU：物理层是比特，数据链路层是帧，网络层是分组/数据报，传输层是 TCP 段或 UDP 数据报，应用层是报文。
- 发送端逐层封装，接收端逐层解封装；协议号、端口等字段用于分用。

### 3. 性能与物理层

```text
发送时延 = 数据长度 / 发送速率
传播时延 = 链路长度 / 传播速度
总时延 = 发送 + 传播 + 处理 + 排队
```

- 带宽高只会减小发送时延，不代表传播时延小。
- 端到端吞吐量通常受瓶颈链路限制。
- 时延带宽积表示链路中可同时存在的数据量；RTT 是一次往返时间，窗口利用率计算要明确是否包含 ACK 发送和处理时间。
- 文件传输题先确认：是否计首部和握手、能否流水、是否等确认、是否存储转发。
- 掌握奈奎斯特、香农公式；编码包括不归零、曼彻斯特、差分曼彻斯特和 4B/5B，调制包括 ASK、FSK、PSK；了解双绞线、同轴电缆、光纤及中继器、集线器作用。

### 4. 数据链路层

- 成帧与透明传输：字符填充、零比特填充。
- 差错控制：奇偶校验、CRC、海明码。
- 可靠传输：停等、GBN、SR。
- 复用：FDM、TDM、WDM、CDMA；介质访问：ALOHA、CSMA/CD、CSMA/CA、令牌。
- 以太网：MAC 帧、最小帧长、争用期、二进制退避。
- CSMA/CD 为保证发送端仍在发送时检测到最远碰撞，要求最短帧发送时间不小于两倍最大单向传播时延。
- PPP 面向点到点链路；HDLC 是面向比特的链路层协议；VLAN 在交换网络中划分广播域。
- 网桥和交换机按 MAC 地址转发；802.11 无线局域网通过 AP 和 CSMA/CA 组织接入，帧地址含义按 To DS/From DS 位判断。

设序号字段 `n` 位：

```text
GBN：发送窗口 WT ≤ 2ⁿ - 1，接收窗口通常为 1
SR：通常 WT = WR ≤ 2⁽ⁿ⁻¹⁾
```

GBN 出错后重传出错帧及其后未确认帧；SR 只重传具体丢失/出错帧，可缓存失序帧。

交换机自学习：

```text
按源 MAC 学习入端口 → 查目的 MAC
→ 未知则除入端口外泛洪
→ 已知且端口不同则定向转发
→ 目的端口等于入端口则过滤
```

| 设备 | 层次 | 隔离冲突域 | 隔离广播域 |
|---|---|---:|---:|
| 集线器 | 物理层 | 否 | 否 |
| 交换机 | 数据链路层 | 是 | 无 VLAN 时否 |
| 路由器 | 网络层 | 是 | 是 |

### 5. ARP、IP 与逐跳转发

ARP：在同一链路上，由下一跳 IP 获得下一跳 MAC。若目的主机不在本网络，帧的目的 MAC 是默认网关接口 MAC，而 IP 目的地址仍是远端主机 IP。

- IPv4 首部重点：总长度、标识/标志/片偏移、TTL、协议、首部校验和、源/目的地址。
- DHCP 自动配置地址；ICMP 负责差错报告与询问；IGMP 管理 IPv4 组播成员关系。
- 了解 IP 组播、移动 IP、IPv6 地址表示及 IPv4/IPv6 过渡。
- 路由器由路由选择与分组转发两部分组成：控制平面形成路由表，数据平面按转发表高速转发。

经过普通路由器时：

| 字段 | 是否变化 |
|---|---|
| 源/目的 MAC | 每跳重新封装，改变 |
| 源/目的 IP | 通常不变，NAT 除外 |
| TTL | 每过一个路由器减 1 |
| IP 首部校验和 | 因 TTL 变化而重算 |
| TCP/UDP 端口 | 通常不变，NAPT 除外 |

拓扑题对每一跳都列：

```text
发送设备 | 接收设备 | 源 MAC | 目的 MAC | 源 IP | 目的 IP | 下一跳
```

### 6. 子网划分与路由

子网划分：

1. 根据主机数求主机位，通常需扣除网络地址和广播地址。
2. VLSM 按主机需求从大到小分配。
3. 写网络地址、广播地址、可用范围。
4. 检查重叠和是否超出原地址块。

CIDR 用前缀长度表示地址块；路由聚合必须满足地址连续、块大小为 2 的幂且聚合前缀边界对齐。

```text
地址块大小 = 2^(32-前缀长度)
通常可用主机数 = 地址块大小 - 2
```

路由转发：

```text
提取目的 IP → 与各表项掩码按位与
→ 找全部匹配项 → 选最长前缀
→ 确定出接口/下一跳 → ARP → 重新封装帧
```

| 协议 | 范围 | 核心 |
|---|---|---|
| RIP | AS 内部 | 距离向量、跳数；15 跳以内可达 |
| OSPF | AS 内部 | 链路状态、Dijkstra |
| BGP | AS 之间 | 路径向量、策略、AS_PATH |

IPv4 分片：每片最大数据长度为 `MTU-IP首部`；除最后一片外，数据长度须为 8 B 整数倍；片偏移单位为 8 B；最后一片 `MF=0`。

### 7. TCP

- UDP 面向报文、无连接，首部只有源端口、目的端口、长度和校验和等基本字段。
- TCP 首部重点：源/目的端口、seq、ack、首部长度、标志位、窗口、校验和及选项。
- SYN、FIN 各消耗 1 个序号；纯 ACK 通常不消耗序号。
- 携带 `n` 字节数据消耗 `n` 个序号。
- 确认号表示“下一个期望收到的字节序号”。

三次握手：

```text
C→S：SYN=1, seq=x
S→C：SYN=1, ACK=1, seq=y, ack=x+1
C→S：ACK=1, seq=x+1, ack=y+1
```

四次挥手：A 发 FIN，B 回 ACK；B 发 FIN，A 回 ACK。双方分别关闭发送方向，FIN 也消耗序号。

```text
实际发送窗口 = min(cwnd, rwnd)
```

- `rwnd` 是接收方通告的流量控制窗口。
- `cwnd` 是发送方维护的拥塞控制窗口。
- 累积确认默认确认连续收到的最高字节，SACK 可报告非连续已收区间；零窗口探测用于避免窗口重新开放通知丢失后双方永久等待。
- RTO 根据 RTT 的平滑估计及波动动态计算，具体数值按题设公式逐次更新。
- 慢开始近似按 RTT 指数增长；到 `ssthresh` 后进入拥塞避免。
- 超时和三个重复 ACK 的处理细节可能因题目采用的 TCP 版本不同，必须以题设为准。

TCP 综合题统一画表：

| 时刻 | 方向 | 标志位 | seq | ack | 数据长度 | cwnd | rwnd |
|---|---|---|---:|---:|---:|---:|---:|

### 8. 应用层

- DNS：递归/迭代查询，资源记录，端口 53。
- HTTP：请求/响应、持久连接、状态码、Cookie、RTT 计算。
- HTTPS 在 HTTP 与 TCP 之间引入 TLS，提供加密、完整性校验和身份认证。
- FTP：控制连接和数据连接分离。
- FTP 主动/被动模式的差别在于数据连接由哪一端发起，控制连接始终由客户端建立。
- DHCP：Discover、Offer、Request、ACK，初期常用广播。
- 邮件：SMTP 负责发送，POP3/IMAP 负责读取，MIME 扩展非纯文本内容的表示。
- SNMP 用于网络管理；Telnet 提供明文远程登录，安全场景通常由 SSH 取代。

访问网站的典型链条：

```text
DNS → 判断是否同网段 → ARP 获取主机/网关 MAC
→ TCP 建连 → HTTP 请求与响应 → TCP 释放连接
```

### 9. 计网大题优先级

1. IP 子网划分、最长前缀匹配和逐跳转发。
2. TCP 握手、挥手、序号、窗口、拥塞控制和传输时间。
3. 交换机自学习、ARP 和 MAC 帧变化。
4. GBN/SR、时延与吞吐量。
5. 应用层综合、IP 分片。

## 六、跨科目连接

### 1. 虚拟地址访问

```text
指令寻址得到虚拟地址
→ MMU/TLB 查映射
→ 页表有效则形成物理地址
→ 访问 Cache/主存
→ 页面不在主存则 OS 处理缺页
```

### 2. 文件读取

```text
进程调用 read → 系统调用进入内核
→ 文件系统由目录/inode 找到磁盘块
→ 驱动启动控制器 → DMA 搬运数据
→ 中断通知 OS → 唤醒进程
```

### 3. 网络收发

```text
进程调用 socket/send/recv → 进入内核
→ OS 维护套接字和缓冲区
→ TCP/UDP、IP、链路层依次封装
→ 网卡 DMA 收发 → 中断通知 OS
→ 按端口交给目标进程
```

### 4. 高频跨科组合

| 组合 | 核心关系 |
|---|---|
| Cache + TLB + 页表 + 缺页 | 硬件缓存与 OS 虚拟内存协同 |
| 进程调度 + 中断 + CPU 周期 | 事件何时触发调度及现场切换 |
| 文件索引 + 磁盘调度 + 树 | 元数据定位、盘块访问、索引结构 |
| C/汇编 + 栈帧 + 数据结构栈 | 函数调用与运行时存储 |
| TCP 窗口 + GBN/SR | 字节流与帧级可靠传输的区别 |

## 七、真题逻辑：把知识点变成得分步骤

真题通常不是要求复述一章，而是给出一个系统场景，让若干机制连续运行。统一模型是：

```text
题设条件 → 建立初始状态 → 按规则触发事件
→ 每一步更新状态 → 得到最终地址/序列/时间/结构
→ 用边界条件验算
```

### 1. 读题时先抓五类信息

| 信息 | 典型内容 | 为什么重要 |
|---|---|---|
| 对象 | 结点、页、进程、Cache 块、帧、报文段 | 明确谁在变化 |
| 初态 | 初始为空、已在内存、队列顺序、窗口值 | 决定第一步和访问次数 |
| 规则 | 替换/调度/路由/排序算法 | 决定状态转移 |
| 时间或地址单位 | bit/B、周期、页号、块号、序号 | 防止量纲和编号错误 |
| 终止条件 | 处理完全部请求、全部确认、找到目标 | 防止少算或多算 |

### 2. 四科各自的推理主轴

| 科目 | 真题推理主轴 | 草稿上必须留下的证据 |
|---|---|---|
| 数据结构 | 维护算法不变量，逐次修改结点/序列 | 指针变化图、递归含义、逐趟序列 |
| 计组 | 沿地址和数据通路逐级追踪 | 位段划分、访问序列、微操作/流水表 |
| 操作系统 | 按事件时间线推进进程和资源状态 | 甘特图、信号量值、页框表、索引层级 |
| 计网 | 按层次、逐跳、逐报文推进 | 每跳地址表、路由匹配、TCP seq/ack 表 |

### 3. 高频真题母题的标准产物

| 母题 | 解题逻辑 | 最终应呈现 |
|---|---|---|
| 链表/树/图算法 | 先定义输入输出与不变量，再处理边界和复杂度 | 伪代码/代码、正确性说明、复杂度 |
| Cache 数组访问 | 地址拆分→块序列→映射/替换→统计 | Tag/组号/偏移、逐次命中表 |
| 数据通路 | 指令语义→数据路径→节拍→控制信号 | 微操作序列和控制信号 |
| PV | 主体→资源→前驱→容量→P/V→死锁检查 | 信号量初值和完整进程代码 |
| 页面置换 | 地址转页号→逐页访问→命中/缺页→淘汰 | 页框状态表和缺页/置换次数 |
| 文件索引 | 字节偏移→逻辑块→索引级别→缓存状态 | 访问的索引块、数据块和访盘次数 |
| 子网与路由 | 主机需求→前缀→地址范围→最长前缀匹配 | 子网表、匹配项、出接口/下一跳 |
| TCP | 标志位和数据长度→更新 seq/ack→更新窗口 | 按时间排列的报文段表 |

### 4. 真题验算规则

- 数据结构：结点没有丢失或重复，首尾指针正确，复杂度满足题目限制。
- 计组：地址位数相加等于总位数；容量、块数、组数单位一致；每个微操作的数据来源存在。
- 操作系统：资源总量守恒；阻塞进程不能直接运行；缺页次数不小于置换次数；访盘次数服从缓存条件。
- 计网：子网不重叠；最长前缀确为最长；MAC 逐跳变化而普通转发中的端到端 IP/端口保持；`ack` 指向下一个期望字节。

## 八、真题学习闭环

### 1. 做题前：识别母题

```text
题目模拟什么系统过程？
→ 已知的初值、容量、地址长度、算法和缓存状态是什么？
→ 要求计算、设计还是解释？
→ 属于哪个母题？
→ 正确流程经过哪些机制？
→ 哪些边界条件会改变结果？
```

| 关键词 | 立即联想到 |
|---|---|
| 必须在……之后 | 前驱信号量，初值 0 |
| 共同使用一个 | 互斥信号量，初值 1 |
| 最多允许 `n` 个 | 资源信号量，初值 `n` |
| 页大小、页表项、虚拟地址 | 地址拆分与页表项定位 |
| 页面序列、页框数 | 页面置换模拟 |
| 盘块大小、地址项大小 | 多级索引覆盖和访盘次数 |
| Cache 容量、块大小、相联度 | Tag/组号/块内偏移和命中模拟 |
| 数据通路、寄存器、控制信号 | 微操作和节拍 |
| IP、前缀、主机数量 | 子网划分 |
| 目的 IP、路由表 | 最长前缀匹配 |
| MSS、seq、ack、cwnd、rwnd | TCP 时间线 |
| 窗口、序号位数、利用率 | GBN/SR |

### 2. 每章最小闭环

1. 闭卷写：本章解决什么问题、为什么产生、靠什么机制、完整流程是什么。
2. 对照教材，只补回忆不出、顺序混乱和容易混淆的内容，不重抄整章。
3. 总结 2～3 条与其他章节或科目的直接联系。
4. 真题先拆成“条件 → 母题 → 路径 → 陷阱”，再限时完整作答。
5. 按错因定点修复：

| 错因 | 修复方法 |
|---|---|
| 记忆缺失 | 闭卷复述后再核对 |
| 概念混淆 | 写区别、联系和反例 |
| 流程断裂 | 重画事件顺序或数据流 |
| 母题不熟 | 提炼固定解题步骤并做同类题 |
| 边界遗漏 | 单列初值、编号、缓存和抢占条件 |
| 计算错误 | 立即做一道同类变式 |
