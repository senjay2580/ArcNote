# 四科大题专题频率统计与考法拆解

> 历史频率范围：2009—2025 年；2026 年题型另列。跨章综合题可重复归类。

| 题型               | 题量  | 分值  | 说明                                           |
| ------------------ | ----- | ----- | ---------------------------------------------- |
| 单项选择题         | 40 题 | 80 分 | 数据结构 1-11，计组 12-22，OS23-32，计网 33-40 |
| 综合应用题（大题） | 7 题  | 70 分 | 41-42 数据结构，43-44 计组，45-46OS，47 计网   |

## 一、四科刻意练习框架

### 1. 选择题支撑知识图

大题训练之外，选择题按章节热度覆盖，括号内为历史真题中的题量级别：

| 科目 | 必须高强度覆盖 | 重点覆盖 | 过纲兜底 |
|---|---|---|---|
| 数据结构 | 树与二叉树（38）、查找（38）、排序（36） | 图（31）、栈/队列/数组（26） | 复杂度（7）、线性表（7）、串/KMP（3） |
| 计组 | 数据表示与运算（40）、存储系统（38） | CPU（31）、I/O（28）、指令系统（19） | 总线（17）、系统概述与性能（15） |
| 操作系统 | 进程与调度（36）、内存管理（34）、文件系统（30） | 概述（28）、同步互斥与死锁（22） | I/O 与磁盘（20） |
| 计算机网络 | 数据链路层（34）、网络层（31） | 传输层（26） | 应用层（16）、物理层（15）、体系结构（14） |

高频章节重点练过程与计算，低频章节至少完成概念辨析和公式覆盖。

### 2. 训练优先级

按“确定性 × 分值 ÷ 训练成本”排序：

1. OS：PV 四骨架——互斥、资源计数、先后同步、前驱图。
2. 计组存储走廊 + OS 页表——虚拟地址→TLB→页表→物理地址→Cache。
3. 数据结构算法题——先写可提交的暴力解，再用七骨架优化。
4. 计组机器码三件套——相对寻址、大小端、标志位。
5. 计网拓扑旅程图——子网、路由、ARP/NAT、TCP 分开推进后再合并。
6. 各科选择题按稳定槽位组卷查漏。

### 3. 每科“练到位”的可观察标准

| 科目 | 达标标准 |
|---|---|
| 数据结构 | 10 分钟内必有正确暴力解；能说明不变量、复杂度和优化点 |
| 计组 | 地址位段和单位换算零犹豫；能沿数据通路写出每个节拍 |
| 操作系统 | PV 题 5 分钟内列出信号量含义、初值、谁 P/谁 V；页表题逐级定位不跳步 |
| 计算机网络 | 子网题约 90 秒完成；拓扑题逐跳写清 MAC/IP/端口变化；TCP 用表格推进 |

### 4. 单题闭环

```text
限时作答
→ 按官方给分点判分，而非只看最终答案
→ 错误归因：概念口径错 / 计算链条错 / 场景建模错
→ 回到同一母题做一道变式
→ 3 天后无提示重做
```

建议时限：选择题平均 90～120 秒；大题按分值分配约 13～20 分钟，总计控制在 100～110 分钟。可参考：数据结构算法 20 分钟、数据结构应用 15 分钟、计组两题各 16 分钟、OS 两题各 15 分钟、计网 13 分钟，共约 110 分钟。算法题必须写设计思想、代码和复杂度；过程题必须保留状态表、时间线或地址拆分，理由本身常是独立得分点。

### 5. 三遍真题循环

- 一刷按年份：发现盲区，记录错因和失分位置。
- 二刷按专题：Cache、PV、页表、算法骨架、网络旅程图等母题串刷。
- 三刷全真限时：训练题序、时间分配和跳题纪律；建议选择题控制在 70 分钟内，大题留 100～110 分钟。

### 6. 做题统一逻辑

```text
识别题目场景和母题
→ 抄清初值、单位、编号和缓存/队列状态
→ 选择固定草稿形式（表格/时间线/地址图/指针图）
→ 按规则逐步更新状态
→ 对照边界条件与守恒关系验算
```

不要把“看懂答案”当完成。真正完成的标准是：隔 3～7 天能闭卷重建流程，并解释每个题设条件为什么会改变答案。

## 二、数据结构（45 分，2 道大题）

### 专题 1：算法设计题（41 题，13 分）★★★★★（17/17 年，每年必考）

**考频**：每年一道，要求写 C/C++ 代码，是数据结构的拉分题。

**按数据结构类型统计**

|     类型      |                 出现年份                 |   次数   | 占比 |
| :-----------: | :--------------------------------------: | :------: | :--: |
| 顺序表 / 数组 | 2010, 2011, 2013, 2016, 2018, 2020, 2025 | **7 次** | 41%  |
|    单链表     |          2009, 2012, 2015, 2019          | **4 次** | 24%  |
|    二叉树     |             2014, 2017, 2022             | **3 次** | 18%  |
|      图       |             2021, 2023, 2024             | **3 次** | 18%  |

**核心解题思想**（按频率）：

1. **双指针 / 快慢指针** — 链表题标配（2009 倒数第 k、2012 公共后缀、2019 重排）
2. **空间换时间（hash / 打表）** — 数组题优化（2015 去重、2018 最小正整数）
3. **贪心 + 指针后移** — 有序数组题（2011 中位数、2020 三元组）
4. **递归遍历** — 树题图题（2014 WPL、2017 中缀表达式、2022 判断 BST）
5. **类快排划分** — 数组分区（2016 划分两子集）
6. **两两抵消（Boyer-Moore）** — 主元素问题（2013）

**真题例证**：

- 2025：数组 A [i] 与 A[j](i≤j)乘积最大值 → 从右到左维护 max/min，O (n)
- 2024：判断唯一拓扑序列 → 拓扑排序中每次入度为 0 的顶点是否唯一
- 2020：三元组最小距离 → 三指针贪心，每次移动最小元素指针
- 2019：链表重排 (a1,an,a2,an-1,...) → 找中点 + 第二段逆置 + 交替插入
- 2013：主元素 → 两两抵消法，候选 + 验证两步

**备考要点**：顺序表和链表占 65%，是重中之重。树和图的算法题近年增加（2021-2024 连续 4 年考图 / 树），需重视图的遍历（DFS/BFS）和拓扑排序。算法题通常按设计思想、代码正确性和复杂度分档给分，具体分值服从当年评分细则；即使代码写不全，也要写清设计思想和复杂度以争取步骤分。

### 专题 2：数据结构应用题（42 题，10 分）★★★★★（17/17 年，每年必考）

**考频**：每年一道，不写代码，模拟 / 计算 / 分析。

**按专题统计**：

|                     专题                      |       出现年份        | 次数 |
| :-------------------------------------------: | :-------------------: | :--: |
| 图（最短路径 / 关键路径 / 拓扑 / 最小生成树） | 2009, 2011, 2025, ... | 高频 |
|       查找（散列表 / B 树 / 折半查找）        |    2010, 2024, ...    | 高频 |
|           树（哈夫曼树 / 前缀编码）           |    2012, 2020, ...    | 中频 |
|        排序（算法过程模拟 / 性能比较）        |       隔年出现        | 中频 |

**核心考法**：

1. **散列表构造** — 给定关键字序列 + 散列函数 + 冲突处理（线性探测 / 平方探测），画表 + 算装填因子 + 算 ASL 成功 / 不成功
2. **AOE 网关键路径** — 算 ve/vl、关键活动、时间余量、活动延期影响（2011、2025 考了）
3. **最短路径** — Dijkstra 算法模拟，或辨析某种贪心策略是否正确（2009）
4. **哈夫曼树 / 编码** — 构造哈夫曼树、WPL 计算、前缀编码判断（2012、2020）
5. **排序算法模拟** — 给定序列，模拟某排序算法的每一趟结果
6. **B 树插入删除** — 画出插入 / 删除后的 B 树结构

**真题例证**：

- 2025：AOE 网 4 问（最短时间 12、关键活动 a/e/m/n、活动 j 余量 6、b 延期处理）
- 2024：平方探测散列表，H (key)=(key×3)%11，H_k=(H_0+k²)%11
- 2010：线性探测散列表，7 个关键字，ASL 成功 = 12/7，不成功 = 18/7
- 2012：6 个有序表合并，哈夫曼思想，WPL=825 次比较
- 2009：贪心选最近顶点能否求最短路径 → 不能，举反例

**备考要点**：散列表和 AOE 网是最高频的应用题考点。散列表必须区分 ASL 成功（按关键字算）和 ASL 不成功（按散列地址算）。AOE 网记住 "最早从左到右取大、最晚从右到左取小、余量 = vl-ve - 边长"。

**数据结构应用题分型**：

| 类型 | 代表考法 | 历史出现次数 |
|---|---|---:|
| 图的应用 | AOE、Prim、Dijkstra、MST 建模、邻接矩阵幂 | 至少 7 次 |
| 散列与 ASL | 构造散列表、装填因子、成功/失败 ASL | 3 次 |
| 排序应用 | 最佳归并树、置换-选择、TOP-K 方案比较 | 3 次 |
| 树的性质 | 正则 k 叉树公式、前缀编码判定 | 2 次 |
| 结构设计 | 可循环利用空闲结点的链式队列 | 1 次 |
| 组合计数 | 出栈序列与卡特兰数 | 1 次（2026 新） |

**2026 增量信号**：

- 41 题从近年图载体轮换回 BST：寻找与 `K` 差的绝对值最小的全部结点，本质是“中序单调性 + 遍历维护极值”。
- 42 题把出栈序列计数放进大题：`n` 个元素的合法出栈序列数为 `C(2n,n)/(n+1)`，说明公式型结论也可能成为完整推导题。
- 命题规律不是死背题型，而是“教材性质 → 程序验证或过程推导”。例如：BST 中序有序→判 BST/找最接近值；欧拉路径→统计奇度顶点；拓扑序唯一→每一步入度为 0 的顶点唯一。

**数据结构七个代码骨架**：

1. 一次遍历维护极值或计数。
2. 双指针：快慢、固定间距、首尾对齐。
3. 原地逆置。
4. 标记/计数数组，以空间换时间。
5. 二分/分治，包括快速排序划分。
6. 邻接矩阵或邻接表遍历、行列计数。
7. 树的递归遍历并携带状态参数。

**需要直接掌握的结论与过程**：

- 二叉树高度范围：最低为 `⌈log₂(n+1)⌉`，最高为 `n`；正则 k 叉树的叶结点数可由边数守恒推导。
- 外排序：k 路归并趟数 `⌈log_k(初始归并段数)⌉`；同时掌握置换-选择和最佳归并树。
- 森林转二叉树后的高度/层次变化、邻接矩阵 `A^m` 中元素的路径计数含义。
- 低频命题空间：并查集、红黑树、分块查找、B+ 树、邻接多重表/十字链表、败者树。定位为补缺区，不占用主训练线时间。

## 三、计算机组成原理（45 分，2 道大题）

### 专题 3：Cache 存储器 ★★★★★（约 15/17 年，几乎每年必考）

**考频**：组成原理第一高频考点，近 5 年出现率 100%。常与虚拟存储器 / TLB 联合出题。

**核心考法**：

1. **三种映射方式** — 直接映射、全相联、组相联（8 路组相联最常考）
2. **地址结构划分** — 标记位 + 组号 / 行号 + 块内地址
3. **命中率 / 缺失次数计算** — 数组按行 / 列优先访问的差异
4. **Cache 总容量计算** — 数据区 + 标记区 + 有效位 + LRU 位 + 修改位
5. **写策略** — 直写 (Write Through) vs 回写 (Write Back)
6. **替换算法** — LRU 控制位数量取决于题设实现；若每行记录年龄，常按每行 `⌈log₂(路数)⌉` 位计算，不能把整组状态一概写成 `log₂(路数)` 位

**真题例证**：

- 2025：8 路组相联，32KB 数据区，64B 块，数组 d [2048] 起始偏移 32B，缺失率 3.15%，平均访问 8.24 周期，跨 3 页缺页 3 次
- 2024：与指令系统联动，Cache + 页式分析数组跨页
- 2020：8 路组相联 + 直写 + LRU，数组 s [1024] 访问缺失 64 次
- 2018：Cache 总容量 + 映射方式 + TLB
- 2014：Cache 数据区容量 + 命中率
- 2010：直接映射，程序 A 行优先 vs 程序 B 列优先，命中率差异巨大
- 2013：8 体交叉存储 + Cache 命中率 + 总线带宽

**备考要点**：组相联映射是绝对重点。公式：组数 = Cache 数据区容量 /(块大小 × 路数)。数组连续访问覆盖块数应按 `ceil((起始块内偏移+访问字节数)/块大小)` 计算，不能机械“加 1”。读操作和写操作（如 `d[i]=d[i]/x`）是否各算一次访问，要按实际访存与写策略判断。

### 专题 4：指令系统与数据通路 ★★★★★（约 13/17 年，高频）

**考频**：近年必考，通常是 43 题，题干给出指令格式和数据通路图，分析控制信号。

**核心考法**：

1. **指令格式分析** — 操作码位数、寄存器数、寻址方式、立即数范围
2. **数据通路控制信号** — 每个节拍的功能和有效控制信号（MDRin/MDRout/ALUctr 等）
3. **ALU 操作与标志位** — 加法 / 减法 / 移位，OF（溢出）/CF（进位）/ZF/SF
4. **寻址方式** — 寄存器直接 / 间接、相对寻址、立即寻址、变址
5. **机器码与汇编互转** — 给定机器码反推指令，或汇编生成机器码

**真题例证**：

- 2024：RISC-V 格式（add/slli/lw），问通用寄存器数（32 个）、shamt 为何 5 位、ALUBsrc 取值、OF/CF 计算、Ext 扩展器选择、机器码 A040A103H 反推为 lw
- 2021：数据通路，ALU 加 / 减时 OF 逻辑表达式、取指阶段控制信号序列
- 2015：数据通路控制信号分析
- 2010：指令格式 + 寻址方式，MAR/MDR 位数，add (R4),(R5)+ 机器码计算
- 2009：数据通路，ADD (R1),R0 执行阶段每个节拍的功能和控制信号

**备考要点**：数据通路题看起来复杂但套路固定。关键是看懂数据流动方向：Xout 表示寄存器 X 输出到内总线，Xin 表示从内总线打入寄存器 X。ALUctr 控制运算类型。OF 判断：同号数相加而结果符号与操作数相反时溢出，也可用次高位进位与最高位进位异或判断。

### 专题 5：数据表示与运算 ★★★★☆（约 10/17 年，高频）

**考频**：隔年出现，近年有增加趋势（2020 补码乘法、2025 补码除法）。

**核心考法**：

1. **补码加减运算** — 真值与机器数转换、溢出判断
2. **补码乘法** — Booth 算法 / 原码一位乘，64 位乘积
3. **补码除法** — 加减交替法，余数 / 商寄存器，除法异常
4. **IEEE754 浮点数** — 单精度格式、规格化、int/float 转换
5. **类型强制转换** — 同位宽有符号/无符号整数转换通常保持位模式、改变解释；扩展、截断及 `int↔float` 需按各自规则处理
6. **结构体对齐与大小端** — 按成员对齐规则计算偏移，再按端序解释多字节数据

**真题例证**：

- 2025：补码除法器，R (高 32 位余数)/Q (低 32 位商)/Y (除数)，符号扩展 SEXT，除法异常（除 0 和 - 2³¹÷(-1) 溢出）
- 2020：补码乘法与编译器循环实现；带符号/无符号乘法结果是否相同取决于操作数解释、结果位宽及截取范围，不能推广为一般结论
- 2017：int 和 float 类型转换、IEEE754 表示
- 2011：8 位字长，unsigned/int 加减，寄存器内容（十六进制）、真值（十进制）、溢出判断、同一加法器实现四种运算

**备考要点**：补码运算的核心是“模 `2^n`”。同位宽整数在有符号/无符号之间转换时通常保持位模式、改变解释；`int↔float`、扩展或截断会改变表示，必须按转换规则处理。除法异常主要看除数为 0，以及 `-2^(n-1)÷(-1)` 的有符号溢出。IEEE754 单精度：1 位符号 + 8 位阶码（偏置 127）+ 23 位尾数（规格化数隐含首位 1）。

**选择题支撑区**：DRAM 刷新、主存扩展与多体交叉，微程序/硬布线控制器，总线带宽与突发传送，`CPU 时间=指令数×CPI×时钟周期` 及 MIPS/MFLOPS 换算。这些通常不是独立大题，但会成为 Cache、数据通路和 I/O 大题的小问条件。

### 专题 6：指令流水线 ★★★★☆（约 8/17 年，隔年出现）

**考频**：2012-2014 连续考，之后隔年出现。

**核心考法**：

1. **流水线时空图** — 画出指令执行过程
2. **吞吐率 / 加速比 / 效率** — 计算
3. **数据冒险 / 控制冒险** — 转发（旁路）、阻塞（气泡）、LOAD-use 冒险
4. **流水线 CPI 计算** — 理想 CPI=1，冒险导致阻塞

**真题例证**：

- 2014：流水线阻塞分析，I1 和 I5 数据相关
- 2013：流水线性能计算
- 2012：指令流水线

**备考要点**：在经典五级流水线且具备常见旁路的题设下，LOAD-use 冒险通常仍需阻塞一个周期，其他部分数据冒险可用转发消除；具体停顿数必须服从数据可用时刻和旁路结构。控制冒险可通过预测、延迟槽或冲刷处理。吞吐率 = 指令数 / 总时间。

### 专题 7：I/O 系统与 DMA ★★★☆☆（中频，常隔年或与其他专题合并）

**考频**：2009、2012、2016、2018、2021 考了，约每 2-3 年一次。

**核心考法**：

1. **三种 I/O 方式比较** — 程序查询、中断、DMA 的 CPU 占用率
2. **中断方式计算** — 中断服务程序指令数 ×CPI + 开销，算 CPU 时间百分比
3. **DMA 方式计算** — 块大小、预处理 / 后处理开销、总线请求次数
4. **磁盘参数** — 平均寻道时间、旋转延迟、传输时间、平均访问时间
5. **周期挪用** — DMA 与 CPU 访存冲突时的处理

**真题例证**：

- 2021：磁盘 4 个双面盘片 ×20000 磁道 ×500 扇区 ×512B，7200rpm，地址字段（柱面 / 磁头 / 扇区）位数，平均访问时间，周期挪用 DMA 总线请求次数
- 2018：程序查询 / 中断 / DMA 三种方式比较
- 2016：中断方式
- 2012：DMA+MIPS + 带宽
- 2009：中断 vs DMA，CPU 占用率 2.5% vs 0.1%

**备考要点**：中断方式 CPU 时间 =（中断服务指令数 ×CPI + 开销）× 每秒中断次数。DMA 方式 CPU 时间 =（预处理 + 后处理开销）× 每秒 DMA 次数。磁盘平均访问时间 = 寻道时间 + 旋转延迟（1/2 转）+ 传输时间。

## 四、操作系统（35 分，2 道大题）

### 专题 8：虚拟内存 / 页式存储 ★★★★★（约 12/17 年，OS 最高频）

**考频**：操作系统第一高频大题，2009、2010、2012、2013、2015、2017、2018、2024 等年份均考。

**核心考法**：

1. **地址转换** — 虚拟地址→页号 + 页内偏移→查页表→物理地址
2. **TLB（快表）** — TLB 命中 / 未命中的访问时间计算
3. **缺页异常** — 缺页处理过程、页表项更新、物理地址计算
4. **页面置换算法** — LRU/FIFO/OPT/Clock，模拟置换过程算缺页次数
5. **多级页表** — 页表占用页数、页表项地址计算
6. **页大小与跨页** — 数组 / 数据结构跨多少页、触发几次缺页

**真题例证**：

- 2024：页大小 4MB（页内偏移 22 位），缺页异常后页表项虚拟地址和物理地址计算、页框号更新
- 2018：页表 + 多级页表 + 快表
- 2012：独特的页面置换策略（定时扫描 + 空闲链表复用），判断时间局部性
- 2010：请求分页 + LRU 置换 + 访问时间计算（TLB 初始空，三次访问各需多少时间）
- 2009：请求分页，TLB + 页表 + 缺页，LRU 局部淘汰，虚地址 1565H 物理地址计算

**备考要点**：地址转换是核心：页号 = 虚拟地址 >> 页内偏移位数，页内偏移 = 虚拟地址 &((1<< 偏移位)-1)。TLB 命中时：访 TLB + 访主存；TLB 未命中时：访 TLB + 访页表 + 访主存；缺页时：访 TLB + 访页表 + 缺页中断 (含磁盘 I/O)+ 重新访 TLB + 访主存。

### 专题 9：PV 操作（进程同步互斥）★★★★★（约 16/17 年，几乎每年必考）

**考频**：操作系统第二高频，通常是 46 题，8 分左右。仅极少数年份未独立出题。

**核心考法**：

1. **经典问题变体** — 生产者消费者、读者写者、哲学家进餐的变形
2. **同步关系** — 前趋图 / 流水线式同步（A 完成后 B 才能开始）
3. **互斥关系** — 共享资源（缓冲区、设备）的互斥访问
4. **信号量设计** — 定义尽可能少的信号量，说明作用和初值
5. **临界区判断** — 某段代码是否为临界区

**真题例证**：

- 2025：植树问题（甲挖坑→乙放苗填土→丙浇水），铁锹互斥 + 坑数同步 (最多 3 个未用坑)+ 流水线同步
- 2024：缓冲区 C1 写 / C2 读 / C3 修改，B 空才能写、非空才能读 / 改，C2 和 C3 互斥
- 2020：前驱关系（A、B 完成后 C，C、D 完成后 E）
- 经典：生产者消费者（empty/full/mutex 三个信号量）、读者写者（读多写少）、哲学家进餐（防止死锁）

**备考要点**：先画所有同步关系（谁等谁）、互斥资源和容量限制，再用尽可能少且含义清晰的信号量表达。前驱同步量常初值 0，互斥量常初值 1，资源计数量初值为资源数；一个信号量可以表达一组等价约束，不必机械地“一条关系一个”。P/V 顺序必须根据资源语义和死锁风险推导，“先同步后互斥、先释放互斥再通知同步”只是常见安全结构，不是无条件通则。

### 专题 10：文件系统 ★★★★☆（约 9/17 年，高频）

**考频**：2011、2012、2013、2014、2018、2022 等年份考了。

**核心考法**：

1. **文件物理结构** — 连续 / 链式 / 索引三种方式的选择与比较
2. **混合索引** — 直接地址项 + 一级 / 二级 / 三级间接，计算最大文件长度
3. **FCB 与索引节点** — 目录项结构、索引节点内容、打开文件读盘次数
4. **文件操作** — 插入 / 删除记录的访盘次数
5. **文件目录** — 目录项、路径解析

**真题例证**：

- 2022：磁盘块 4KB，索引节点 256B，10 个直接 + 一 / 二 / 三级间接各 1 个，目录项 = 文件名 + 索引节点号，问目录项内容、文件块号、打开文件读盘次数、6MB 文件用哪几级间接
- 2014：连续分配 vs 链接分配，插入第 30 条记录的访盘次数（59 次 vs31 次），链接文件最大长度
- 2012：混合索引（预分配连续区 + 直接索引），4TB 空间，1KB 块，512B 索引表，求最大文件长度
- 2011：一次性写入不可修改文件，选连续结构，FCB 设计 <起始块号，块数>

**备考要点**：混合索引最大文件长度公式：(直接项数 + 一级间接项数 ×(块大小 / 地址项大小) + 二级 ×(块大小 / 地址项大小)² + 三级 ×...)× 块大小。打开文件读盘次数：读目录→读索引节点→读文件数据。

### 专题 11：磁盘管理与调度 ★★★☆☆（低中频，多与 I/O 或文件系统结合）

**考频**：2010、2019 考了大题，其他年份多在选择题。

**核心考法**：

1. **磁盘调度算法** — FCFS/SSTF/SCAN (电梯)/CSCAN (循环扫描)/LOOK/CLOOK
2. **磁头移动距离** — 给定请求序列和初始位置，计算移动磁道数
3. **磁盘访问时间** — 寻道时间 + 旋转延迟 + 传输时间
4. **空闲块管理** — 位示图、空闲链表

**真题例证**：

- 2019：磁盘基本结构、调度算法、读取时间
- 2010：CSCAN 调度，2KB 内存管理 16384 个空闲块，6000rpm，100 扇区 / 磁道，计算总访问时间，SSD 无需磁盘调度

**备考要点**：CSCAN 是循环扫描：磁头单向移动处理请求，到端点后立即返回另一端（不处理返回途中请求）。SCAN 是电梯算法：到端点后反向移动处理。SSD 无机械运动，FCFS 即可。

**操作系统全链路题**：近年会从“系统引导、键盘输入、一次文件读取”等动作出发，串联用户态/核心态、系统调用、中断、进程状态、页表、文件系统、驱动、DMA。答题按事件顺序写：

```text
用户操作/系统调用 → 陷入或中断进入内核
→ 保存现场并执行内核/驱动逻辑
→ 必要时进程阻塞、调度其他进程
→ I/O 完成中断 → 唤醒原进程 → 等待再次调度
```

选择题还需覆盖：用户态与核心态、系统调用与库函数、银行家算法、硬链接/符号链接引用关系、设备软件层次与缓冲。

## 五、计算机网络（25 分，1 道大题）

### 专题 12：网络层（子网划分 / 路由 / NAT/ARP）★★★★★（约 11/17 年，最高频）

**考频**：计网大题 60% 以上考网络层，是绝对重点。

**核心考法**：

1. **子网划分** — 定长 / 变长子网划分、子网掩码、可用主机数
2. **路由聚合（CIDR）** — 多个子网聚合成一个超网，最长前缀匹配
3. **路由表构建** — 根据拓扑填写路由表（目的网络、下一跳、接口）
4. **IP 分组转发** — 给定路由器和分组，分析转发过程、TTL 变化
5. **NAT** — 网络地址转换，私有 IP↔公网 IP 映射，端口号
6. **ARP 协议** — 地址解析，IP→MAC，ARP 缓存
7. **路由协议** — RIP/OSPF/BGP 的选择、收敛时间、路由选择

**真题例证**：

- 2024：4 个 AS 互连，结合网络规模、度量上限和收敛需求选择 OSPF；分析 RIP 收敛、BGP eBGP/iBGP 会话、UPDATE 报文和 AS 路径
- 2020：NAT 路由器，分组转换过程
- 2019：各层设备选择、NAT 路由器、IP 地址
- 2018：定长子网划分、IP 数据报分片
- 2015：DHCP、ARP、子网掩码、默认网关
- 2013：路由表构建、路由聚合、分组转发、路由协议选择
- 2009：定长子网划分、路由表构建、路由聚合

**备考要点**：子网划分核心：借 `n` 位主机位做子网位→`2^n` 个子网，每个子网通常有 `2^(主机位)-2` 个可用地址。路由聚合要找连续、边界对齐地址块的共同前缀。基本 NAT 可以只改 IP 地址；NAPT/PAT 才同时利用端口映射。RIP 的不可达度量为 16，适合较小网络，但不能把“15 跳上限”直接等同为“路由器数量必须≤15”；OSPF 适合更复杂的 AS 内部路由，BGP 用于 AS 间策略选路。

### 专题 13：传输层（TCP/UDP）★★★★☆（中频，近年 TCP 综合再次上升）

**考频**：2016、2017、2023 考了大题。

**核心考法**：

1. **TCP 连接管理** — 三次握手（SYN、SYN+ACK、ACK）、四次挥手、标志位
2. **TCP 可靠传输** — 序号、确认号、超时重传
3. **TCP 流量控制** — 滑动窗口、rwnd
4. **TCP 拥塞控制** — 慢启动、拥塞避免、快重传、快恢复，cwnd 变化曲线
5. **可靠传输协议** — GBN（回退 N 帧）、SR（选择重传）

**真题例证**：

- 2023：FTP 协议 + TCP 连接建立标志位 + 拥塞控制窗口变化
- 2017：GBN 协议
- 2016：TCP 连接建立（SYN/SYN+ACK/ACK 标志位）、拥塞控制窗口变化、释放连接状态时间计算、报文序号含义

**备考要点**：TCP 拥塞控制四阶段：慢启动（指数增长到 ssthresh）→拥塞避免（线性增长）→丢包（快重传 3 个冗余 ACK→快恢复，或超时→慢启动）。GBN 发送窗口≤2^n-1，接收窗口 = 1；SR 发送窗口 = 接收窗口≤2^(n-1)。

### 专题 14：数据链路层 ★★★☆☆（约 3/17 年）

**考频**：2010、2021、2022 考了，常与其他层结合。

**核心考法**：

1. **CSMA/CD** — 最短帧长计算、争用期、二进制指数退避
2. **以太网帧** — 帧格式、首部长度、MAC 地址
3. **交换机** — 自学习过程、转发 / 过滤
4. **PPP/HDLC** — 帧格式

**真题例证**：

- 2022：各层设备选择 + 最短帧长计算 + 802.11 帧地址
- 2021：交换机自学习 + ARP
- 2010：CSMA/CD + 以太网帧首部 + 数据传输速率

**备考要点**：最短帧长 = 2× 传播时延 × 带宽（确保发送完前能检测到冲突）。交换机自学习：收到帧时记录源 MAC 和端口，转发时查目标 MAC。

### 专题 15：计网跨层综合考型 ★★★★★

计网大题通常不是单章题，而是给一张拓扑图或一条连接，把若干层的状态连续推进。历年可归为六类：

| 类型 | 主要设问 | 历史出现量级 |
|---|---|---:|
| 地址工程 | 子网划分、聚合、最长前缀、NAT、DHCP | 约 8 次 |
| TCP 精算 | 握手/挥手、seq/ack、窗口逐 RTT、总时间 | 约 4 次，近年上升 |
| 链路效率 | CSMA/CD、停等/GBN、卫星链路、窗口与序号位 | 约 4 次 |
| 组网选型 | 集线器/交换机/路由器、交换表、802.11 地址 | 约 3 次 |
| 十六进制报文解剖 | 从字节流识别 IP/TCP/UDP 字段 | 约 2 次 |
| 路由协议 | RIP 收敛、OSPF 选型、BGP 会话和选路 | 约 2 次 |

**跨层题固定草稿**：

1. 画拓扑并标出每个接口的 IP、掩码和 MAC。
2. 每一跳写一行：`发送方｜接收方｜源/目的 MAC｜源/目的 IP｜端口｜TTL｜下一跳`。
3. 路由器处做最长前缀匹配；普通转发会换 MAC、TTL 减 1，端到端 IP/端口通常不变，NAT/NAPT 例外。
4. TCP 另画时间线，逐段更新 `seq/ack/cwnd/rwnd`；FTP 要区分控制连接和数据连接。
5. 效率题先统一 bit、秒、传播/发送时延，再代停等、GBN/SR 或最短帧公式。

**选择题支撑区**：物理层掌握奈奎斯特/香农、波特率与比特率、曼彻斯特/QAM；体系结构掌握 OSI/TCP-IP 分层；应用层掌握 DNS 递归/迭代、HTTP 持久连接与 RTT、SMTP/POP3、FTP 双连接。
