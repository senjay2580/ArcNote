找到一个基础解系是有条件的 

|          | 极大线性无关组       | 基础解系         |
| -------- | -------------------- | ---------------- |
| 研究对象 | 一组向量             | 齐次方程组的解   |
| 要求     | 最大限度保持线性无关 | 能表示所有解     |
| 向量数量 | 等于这组向量的秩     | 等于 (n-r)       |
| 本质     | 给向量组找“骨架”     | 给解空间找“骨架” |

![image-20260818105857789](https://cdn.jsdelivr.net/gh/kasahuki/os_test@main/img/image-20260818105857789.png)

X是n维的，r是A的秩也是A的维度，A表示将n维的X给拍成r维，而Ax＝0中的x表示在n维X被拍成r维的A的过程中哪些纬度被拍成0维，显然从n维到r维其中有n-r维被拍成了0维，n-r个纬度构成解

| 概念               | 直观理解                       | 数量     |
| ------------------ | ------------------------------ | -------- |
| **主元变量**       | 被方程约束，不能随便取         | (r)      |
| **自由变量**       | 可以自由取，控制“被拍没的方向” | (n-r)    |
| **基础解系**       | 所有“被拍没的方向”的最小骨架   | (n-r) 个 |
| **极大线性无关组** | (A) 中有效独立方向的骨架       | (r) 个   |

| 方程组语言（第3章） | 矩阵语言（第2章） | 向量语言（第4章） |
|---|---|---|
| Ax = b 有解 | r(A) = r(A, b) | b 能被 A 的列向量组线性表示 |
| Ax = b 有唯一解 | r(A) = r(A, b) = n | 表示方式唯一（列向量组线性无关） |
| Ax = b 有无穷多解 | r(A) = r(A, b) < n | 表示方式不唯一 |
| Ax = 0 只有零解 | r(A) = n（方阵：\|A\| ≠ 0） | A 的列向量组线性无关 |
| Ax = 0 有非零解 | r(A) < n（方阵：\|A\| = 0） | A 的列向量组线性相关 |

看懂这张表的关键一步：把 Ax = b **按列拆开**——

> Ax = b 其实就是 x₁α₁ + x₂α₂ + … + xₙαₙ = b （α₁…αₙ 是 A 的各列）

"解方程"瞬间变成"问 b 能不能由这堆列向量拼出来"。**这就是为什么要学向量。**

有解：解要么只有一个，要么有无穷多个
