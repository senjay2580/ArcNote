# 考研数学真题精选：极限 · 一元微分 · 一元积分（2006–2025，数学二 / 数学三）

> 收录范围：函数极限连续、一元函数微分学、一元函数积分学三大专题的选择、填空、解答题；
> 排除多元微分、二重积分、微分方程、级数、线代、概率。只含题目，不含答案。

## 考情总结（基于本题库 387 道真题统计）

### 1. 占比：前三章是绝对大头

| | 数学二 | 数学三 |
|---|---|---|
| 每年入选题数 | 11~13 题 / 全卷 22 题 | 6~10 题 / 全卷 22 题 |
| 卷面分值估算 | **约 60~75 分（满分 150）** | 约 35~50 分 |

数二无级数、概率，一元微积分被反复深挖，**前三章优先级最高**；数三题量较少、难度更平和，带经济应用特色（弹性/边际/利润）。

### 2. 分布：各题型的"固定座位"

- **选择题（第 1~4 题左右）**：无穷小阶的比较、间断点个数与类型、极值点与拐点辨析、抽象函数性质推断。坑全埋在"充分还是必要"上。
- **填空题（第 9~14 题）**：求具体极限、渐近线方程、参数方程/隐函数求导、定积分或反常积分计算。**纯送分题，要求又快又准。**
- **解答题**：
  - 开局题（15/16/17）：几乎固定一道求极限或定积分计算，解答题里最便宜的分；
  - 中段（18/19）：定积分应用——旋转体体积绝对高频，其次面积；数二有弧长和做功/引力/压力，数三换成经济应用；
  - 压轴（20/21）：**中值定理证明题**（"证明存在 ξ 使…"），前三章最难的位置。

### 3. 难度分层

| 层级 | 题目类型 | 特点 |
|---|---|---|
| 送分层（≈40%） | 填空的极限/求导/定积分计算、解答题第一道求极限 | 套路固定，考熟练度 |
| 中档层（≈40%） | 选择的概念辨析、变限积分综合、旋转体/面积应用、数三经济应用 | 考概念是否真懂 + 一次转化 |
| 拔高层（≈20%） | 中值定理证明、导数不等式证明、数列极限（单调有界/夹逼）、抽象函数分析 | 需构造辅助函数，区分度所在 |

近十年趋势：计算量加大（2021 起小题 4 分变 5 分），概念题变"绕"，但套路池基本没变。

### 4. 重点掌握清单（按性价比排序）

1. **求极限的完整工具箱**：洛必达 + 等价无穷小 + 泰勒展开（x→0 常用展开式要条件反射），n 项和转定积分定义；
2. **变限积分求导**：前三章的"万能连接器"，与极值/拐点/极限/方程根均有结合，$\frac{\mathrm{d}}{\mathrm{d}x}\int_0^{\varphi(x)}f(t)\,\mathrm{d}t$ 链式法则必须滚瓜烂熟；
3. **中值定理证明套路**：罗尔定理构造辅助函数（$e^{kx}f(x)$、$xf(x)$ 型）、拉格朗日两次使用、泰勒带余项，压轴题基本从这三招里出；
4. **定积分应用公式**：旋转体体积两个公式（绕 x 轴 / 绕 y 轴柱壳法）、面积；数二加弧长与物理应用，数三加经济应用（边际积分回原函数、弹性公式）；
5. **概念辨析四件套**：间断点分类、无穷小阶比较、极值点 vs 拐点的充分/必要条件、可导 ⇔ 左右导数；
6. **数列极限证明**（拔高）：单调有界准则 + 夹逼，常与不等式证明捆绑，数二尤其爱考。

**一句话总结：前三章 = 数二的命脉、数三的基本盘；小题拼熟练，大题拼"变限积分 + 旋转体 + 中值证明"三大件。** 可直接在本文档内搜索关键词（如"拐点"、"ξ"、"旋转"）做专项集中训练。

**（18）**（本题满分 12 分）设函数 $f(x)$ 在 $x=0$ 处连续，且 $\lim\limits_{x \to 0} \dfrac{x f(x) - \mathrm{e}^{2\sin x} + 1}{\ln(1+x) + \ln(1-x)} = -3$，证明 $f(x)$ 在 $x=0$ 处可导，并求 $f'(0)$.

**（20）**（本题满分 12 分）设函数 $f(x)$ 在区间 $(a,b)$ 内可导. 证明：导函数 $f'(x)$ 在 $(a,b)$ 内严格单调增加的充分必要条件是对 $(a,b)$ 内任意的 $x_1, x_2, x_3$，当 $x_1 < x_2 < x_3$ 时，
$$\frac{f(x_2) - f(x_1)}{x_2 - x_1} < \frac{f(x_3) - f(x_2)}{x_3 - x_2}.$$
