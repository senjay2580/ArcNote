# 第一部分 · 选择题：思维、逻辑与流程

## 1.1 三条判别铁律（最高优先级，其他技巧都是它的下位）

### 铁律一：疑罪从无
> "你觉得他错，他就是对的。你在那疑神疑鬼的时候，他就是对的。"

你**说不清哪里错**的选项 = 对的。多选题里"找不出明显错就全选"，真题里 ABCD 全选的题非常多（25 真题里出现 3-4 次）。

### 铁律二：错就错得明显
> "政治错就错得明显，你不用去纠结它，你越纠结你就越出问题。"

命题人不会靠"把'合规律性'偷换成一个近义词"来阴你。错项一般是**肉眼可见的量级错误、时间错误、唯心表述、绝对化表述**。

### 铁律三：排除法排的是"明显错"，不是"我没见过"
> "你没见过不一定是错的。"（25 真题第 2 题，"人体解剖是猴体解剖的钥匙"因为陌生被大量误排）

**陌生 ≠ 错误。作家名言、书上原话经常长得很陌生。**

## 1.2 词汇雷达：两张必须刻进脑子的词表

### A. 墓碑词（出现即高度警惕，八成是错项）

| 类别 | 词 | 为什么错 | 真题例证 |
|---|---|---|---|
| 精确化 | **具体**（具体环节、各个具体） | 政治看宏观大趋势，落到具体环节就"不一定一样"了 | 25-2题 C 项 |
| 纯粹化 | **单纯、纯粹** | 复杂系统不可能"单纯由…决定" | 25-17题 |
| 自发化 | **自发、自然、自然而然、自然显露** | 价值/意识不会自动产生 | 25-19题 D、22年多选 |
| 绝对化 | **完全、彻底、绝对、任何、所有、一切、无条件** | 现实没有这么极端 | "彻底动摇""无条件服从""所有政党" |
| 加和化 | **总和** | "集体利益是个人利益的总和"——复杂系统不是简单加和，**任何地方都不对** | 25-31题 |
| 完成式 | **已、已经、最终、已成为** | 阶段错误：事情还没到那一步 | "僵局已破解""已完全掌握""已取代实体经济" |
| 同步化 | **同步**（同步实现共同富裕） | 先富带动后富，不可能同步 | 25-25题 D |
| 主导化 | **主导、主体、成为主导地位** | ①发展中国家还没主导国际组织；②"以传统文化为主体的道德体系"= **复古主义**，是标准错误 | 25-19题 B、30题 D |
| 取代化 | **取代、代替** | A 把 B 覆盖掉，太绝对 | 精神取代物质、数字经济取代实体经济 |
| 优越比较 | **比其他文明更优越** | 文明不比优劣 | 25-19题（多选）B |
| 结盟 | **同盟、盟友** | 我国"结伴不结盟、对话不对抗" | 反复复现的干扰项 |

**慎用类**：**根本、首要** —— 这两个词本身不错，但**位置极易错**（见 1.3 的"归位法"）。

### B. 中肯词（出现即高度倾向正确）

> "考研政治里面有个词叫中肯，越中肯的就越选它。"

**重要、不可忽视、影响因素、有助于、有利于、组成部分、深刻变化**

这类词**不做任何强断言**，放在哪儿都成立。看到"重要"基本可以直接放行。

**对比记忆（这是他讲得最透的一个点）**：
- ❌ 23年真题："进博会已成为世界经济增长的**引擎**" → 错。小小一个会 ≠ 世界经济的心脏。
- ✅ 25年真题："数字经济是稳增长促转型的**重要**引擎" → 对。加了"重要"降级 + 数字经济确实不可或缺。
- **"引擎"= 心脏级、没了就动不了。用时必须做"量级匹配"检查。**

## 1.3 七种专项判别工具

### ① 三项解题法（连连看）——最快的一招
题干关键词与某选项**字面重合/同义**，直接选它。
- 题干"多元化食物供给**体系**" → 选项"**系统**思维"（体系=系统）
- 题干"**中非合作**论坛" → 选项含"**合作**"
- 题干"**兴中**会章程" → 口号"**振兴中华**"
- 题干"依靠群众**就地**化解矛盾" → "把矛盾化解在**基层**"

> "初高中小朋友来了连连看都能做对。"

### ② 归位法：政治里"关键/根本"有固定归属
| 问法 | 答案倾向 | 明确**不是**关键的 |
|---|---|---|
| 依法治国的**关键** | 党领导立法、执法、司法 | **监督**（要靠监督说明事已经没干好）、**德治**（辅助性）、**宣传教育** |
| 处理人民内部矛盾的**根本着眼点** | 社会主义建设（量级最大的那个） | 扩大民主、维护稳定、消除矛盾（都不够"根本"） |
| 加强基础研究**归根结底**靠 | **人才**（高水平人才） | 体制机制、国际合作、学科建设布局（钱和布局换不来成果） |

**通用心法：问"根本/关键"时，选量级最大、最上游的那个。**

### ③ 唯心食物链
**意志、思想、意识、兴趣、主观愿望** 在政治里是**食物链最底端，永远不能"决定/驱动"别的东西**。
> "你想考好你就能考好吗？"

看到"由主观意志决定""实践主体的意志是根本动力"→ 直接排。
反之：**说物质的表述几乎不会错**（"观念是移入人脑并经人脑改造过的物质的东西"= 对）。

### ④ 凯东判别法（抽象马原代入生活）
遇到读不懂的马原抽象选项，**把"客体"代成一本具体的书/一门课，把"主体"代成你自己**，然后念一遍看是否成立。
- 原句："客体的价值及价值大小取决于客体的属性及满足主体需要的程度"
- 代入："这本解题密码的价值取决于①书本身编得好不好 ②你需不需要它"
- → 完全成立 → 选。

> "遇到马原抽象的，立刻拿凯东往里面套。"

### ⑤ 多选对立配对法
选项如果构成**两组互斥对立**（公有制 vs 私有制 / 个体劳动 vs 雇佣劳动），题干问"简单/初级阶段"，就在每组里各取靠前的那个。
- 25-20题：简单商品经济基础 → 私有制（早于公有制）+ 个体劳动（早于雇佣劳动）→ 选 BC
- 逻辑："基础不可能又是公有又是私有，这不混乱吗？"

### ⑥ 时间锚定法（史纲专用）
把数字从事件名里"抠"出来：
- **九一八** → 抠 1 → **1931.9.18** → 更早 → **揭开抗战序幕**
- **七七** → 抠 7 → **1937.7.7**（卢沟桥）→ **全国性**抗战起点（题目若抠掉"全国"二字就是坑）
- **一边倒** → 1949 建国时提出（《论人民民主专政》），不是 1956 → 时间错乱型干扰项

> "命题老头就爱考时间错乱。"（29题：十二大提"走自己的路"，不是 92 年南方谈话）

### ⑦ 概念切分法（防混淆）
高频被混的三组，必须切开记：
- **半殖民地**（对应"独立"维度：完全独立→半殖民地→殖民地）｜**半封建**（对应"资本主义"维度：资本主义关系进来了）
- **南北**：南 = 发展中国家，北 = 发达国家（不是地理南北）
- **粮食安全**：指"人人有饭吃、供给保得住"（联合国定义），**不是食品质量安全**；关键在**藏粮于地、藏粮于技**（提高**产能**而非产量），与"供给侧结构性改革"（满足消费者偏好）是两条线

## 1.4 命题人的八种出题手法（反向识别）

1. **真题复现**（最重要）：题干、选项、干扰项都会原样或倒着再考一遍。25-4 题与 2020 年第 4 题**题干一字未改**；25-5 题是 2023 年真题的**反问版**；"盟友关系"干扰项 2014 年出现过、25 年又来。
2. **干扰项复现**：正确项换了，干扰项照抄旧年。
3. **引用作家名言**：读起来陌生但正确（"人体解剖是猴体解剖的钥匙""历史有时会向后作巨大的跳跃"）。
4. **不合题意**：塞一个和题干完全不相干的正确说法（大气污染治理 → 塞"生物多样性保护"；废物循环利用 → 塞"水土流失治理"）。
5. **夸大作用**：把一个小切口说成"根本途径"（"文化建设是解决社会主要矛盾的根本途径"）。
6. **程度/量级错配**：见"引擎"对比。
7. **时间错乱**：把 A 时期的提法安到 B 时期。
8. **单个词考察**：整句只错一个词（抠掉"全国"、把"物质"改"意识"、加个"无条件"）。

## 1.5 选择题实战流程（按顺序执行）

```
第 0 步｜分类题干
   题干是长材料（气候/北斗/人工智能等） → 跳读，直接看选项
   题干含明确限定词（时间、主体、"最突出/关键/根本/依据/魂与根"）→ 必须逐字读

第 1 步｜锁定"问的是哪个维度"
   把设问的核心词圈出来：魂？根？关键？根本？依据？最突出特点？
   （25-1题：魂与根是两个问题，混在一起就错）

第 2 步｜扫墓碑词，一刀切
   已/完全/彻底/总和/无条件/主导/取代/同步/自发/具体/单纯 → 优先排
   意志/思想/兴趣 决定 XX → 排

第 3 步｜量级 & 归位检查
   "引擎/根本/关键/首要" → 对象量级匹配吗？归属对吗？

第 4 步｜连连看
   剩余项里有和题干字面/同义呼应的 → 选它

第 5 步｜中肯度收尾
   "重要/不可忽视/有利于/影响" → 放行

第 6 步｜多选定型
   疑罪从无：说不清哪错的一律保留
   最少 2 个、最多 4 个；找不出明显错就 ABCD 全选
   绝不选 1 个

禁止事项：
   ✗ 不因"没见过"而排除
   ✗ 不在明显对/明显错之外的地方深究
   ✗ 不用做过的模拟题去"回忆"答案（过拟合，25-19题就是被肖四"评价≠价值"带沟里的）
```

# 第二部分 · 大题：抄材料的完整工程流程

## 2.1 总流程（五步，每道题都一样）

```
① 读设问 → 拆出【关键词 A】和【限定角度】
② 回材料"精准定位"：找到与题干同词/同义的那句话
③ 以定位点为中心，向上下扩展 → 用彩笔圈出"可抄区"
④ 搭骨架：开头点题 → 主体分段论述 → 结尾再点题（总-分-总）
⑤ 填充：可抄区改写 + 万能角度水字数 + （马原/史纲）少量必背原理
```

**核心口诀：盯住目标 → 上下都能抄 → 首尾双扣题 → 分段不分点。**

## 2.2 能抄 / 不能抄清单

| ✅ 能抄 | ❌ 不能抄 |
|---|---|
| 总结性话语 | 文学化表达/修辞（"如果你是一滴水…"） |
| 定位句的上下文 | 普通人讲话 |
| 帽子、定性、意义类表述 | **具体数字**（"54万亿增长到114万亿"抄上去分就没了） |
| 政策名、理念名 | 太过具体的实例、文件名 |

**关键认知：标准答案里本来就有大量材料原话。**
- 23年真题标答里"人民群众获得感、幸福感、安全感更加充实"= 材料原句，一字未改。
- 22年 35 题标答的"四个伟大成就"排比 = 22年 36 题**题干**里的原话。
- 所以"抄材料"不是投机，是**命题结构本身允许的解法**。

## 2.3 四种改写术（论文降重四件套）

| 手法 | 操作 | 例子 |
|---|---|---|
| **同义替换** | 换词不换意 | "拓展了发展中国家走向现代化的途径" → "为发展中国家现代化建设提供了中国方案"；"既希望加快发展又希望保持独立的国家和民族" → "其他独立自主的国家" |
| **句式变换** | 正着说改倒着说 / 主宾互换 | "A 是 B 的重要工作，也是 C 的重要工作" → "A 对 B 和 C 都具有非常重要的意义"；"A 支撑 B" → "B 是以 A 为支撑的发展" |
| **拓展补充** | 把一句短话展开成一段 | "这是由我国历史方位和形势任务决定的" → 分别解释"历史方位是什么""形势任务是什么"，各写两句 |
| **概括归纳（上位替换）** | 把具体事/数字抽象化 | "美国退出巴黎协定、世卫组织…" → "美国退出了大量重要国际组织和机制，大搞单边主义、霸权主义，不履行国际义务" |

⚠️ 他的实战建议：**考场上不要精雕细琢改句子，笔不能停，改不动就直接抄**。有考生（江苏）几乎原样腾抄，主观题拿 20 分出头。

## 2.4 水字数引擎（写不满时的两台发动机）

### 引擎 A：题干出现两个东西 → "区联分展物"
> 口诀转录为"区、联、分、展、物"，实际展开是：**区**别 → **联**系 → 不可分割 → **发**展 → **不能**（反对XX主义/两个极端）

套路：A 是 A，B 是 B（区别）→ 联系是普遍的，A 离不开 B（联系）→ 没有离开 A 的 B，也没有离开 B 的 A（不可分割）→ 要用发展的眼光看（发展）→ 我们不能割裂看待，要反对教条主义和经验主义、相对主义和绝对主义（反对式）。

### 引擎 B：题干出现关键词 A，问"为什么重要/如何理解/有何意义" → **13 个角度**
口诀（转录音）"党理之路史文实诚人须环卫"，实为 **12 + 1**：

| # | 角度 | 万能句式 |
|---|---|---|
| 1 | **党**的领导 | 在党的领导下 A 才能充分发展，彰显党领导的优越性 |
| 2 | **理**论 | A 有理论依据，体现某种思想/宗旨；一个东西行归根到底是马克思主义行 |
| 3 | **制**度 | A 与我国制度相关，彰显制度优越性 |
| 4 | **路**线/道路 | **"A 正是我们这条道路在新时代的具体实践和拓展"**（万能功能句） |
| 5 | 历**史** | A 是历史传承、红色血脉延续，是长期探索付出巨大代价的成果 |
| 6 | **文**化 | A 契合中国特色社会主义文化，需与优秀传统文化结合 |
| 7 | 现**实** | A 符合国情、符合社会主义初级阶段、有重大现实意义 |
| 8 | **成**就 | A 带来历史性成就（记"**帮社经**"：帮助**社**会稳定 + **经**济发展，"两大奇迹"） |
| 9 | **人**民 | A 是全过程人民民主的体现，满足人民期待，切实为人民谋福祉 |
| 10 | **需**求 | A 满足经济发展/社会稳定/精神/理论的需要 |
| 11 | **环**境 | 百年未有之大变局，某国大搞单边霸权，A 是我们站稳脚跟的基础 |
| 12 | **未**来 | A 开辟未来，提供中国方案/中国答案，回答时代之问、人民之问、世界之问 |
| +13 | **问题** | 发展中不断出现新问题新考验，A 能帮我们破解发展不平衡不充分等问题 |

**每个角度写 1-2 句，答题卡就满了。全部 13 个角度都是"对"的，判卷不能说你错。**

**戴帽子（万能重要性表述）**：重要基础、重要保障、重要支撑、关键、使命任务、必然要求、应有之义、必由之路、必然选择、题中应有之义……
⚠️ **唯一禁用**："根本""首要"（那是有专属归属的）。

### 引擎 C：三位一体（一个词写出三种意思）
| 想写 | 句式 |
|---|---|
| **原因** | A 是……的必然要求 / 必然选择 |
| **意义** | ……有助于 A |
| **措施** | 我们要 A / 必须坚持 A |

## 2.5 格式硬规则

1. **首尾双点题**：开头把题干改写一遍，结尾再改写一遍（总-分-总）。**必抄**。
2. **分段论述，不分点**：
   > "你水平不高千万别分点。你写的是车轱辘话，小一一句、小二一句，老师看着腻歪；不如写成三大段，看起来像论述。"
   分点只适合能精准踩点的高手。
3. **战术回扣**：论证完意义后补一段"所以我们要坚持它、贯彻它、弘扬它"。
4. **五题同款尾段**：五道大题分别由不同老师批改 → 可以在每题末尾塞同一段万能话。

# 第三部分 · 资源与时间的科学配置（他的元建议）

1. **别拿模拟卷分数评估自己**。肖四肖八选择题里帽子题（死记型）占十几到二十个，真题里少得多；模拟卷考十几分和真题考四十分毫无关系。
2. **性价比排序**：选择题分析能力 > 马原/史纲最小必背集 > 大题语料积累 > 押题背诵。
3. **政治大题不会背也能抄满；英语作文不会背一个字都写不出。** 时间紧就把政治大题的背诵时间挪给英语作文/数学/专业课。
4. **地区意识**：旱区（北京等压分区）主观题给分低，要多背一点；水区抄满就有基本分。
5. **反押题心态**：一个考点能出十个小点，压住话题 ≠ 压住考点。真正稳定可复用的是**真题复现**和**命题手法**，不是模拟卷。

## 最后：这套方法的诚实边界

- 它是**应试启发式**，不是知识替代品。34 马原、36 史纲仍有不可省的最小必背集，纯抄会明显吃亏。
- 选择题的词表是**统计先验**，不是逻辑定理。25 真题第 27 题（中共一大对其他党派的态度）用尽所有方法也做不对——他自己承认，并演示了三个 AI 也答错。遇到这类题认栽，不要因此怀疑方法。
- 大题"抄满得平均分"的结论建立在他自采的问卷样本上，非官方数据，请把它当作**方向性判断**而非分数承诺。
- 他反的是"把选择题命运押在押题上"，不是反对所有押题资料——**大题押题他本人认为肖老 80% 的年份是有效的**。
