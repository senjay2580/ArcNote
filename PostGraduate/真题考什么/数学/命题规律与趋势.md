# 考研数学二 真题命题研究(1987–2025,一手逐题提取)

> 数据源:《考研数学二_真题逐题地图.md》(865题/39年,全年份覆盖)。本文件是全书之纲:**命题人怎么出题**。与《考研数学二_题型卡.md》配对——卡片管按章学,本文件管按命题思维练。

## 〇、大题位次模板(2021改革后6道大题,✅按865题库逐年核验)

> 2004–2020:10选择 + 6填空 + **9道大题**(高数7+线代2)。
> **2021至今**:10选择(50分) + 6填空(30分) + **6道大题(70分)**,即第17–22题(高数5+线代1)。
> 下表每一条都用 865 题库 2015–2025 解答题逐年比对过,与教辅口径不一致处已标注。

### 位次规律(✅硬数据,2015–2025 共11年解答题)

| 断言 | 命中 | 判定 |
|---|---|---|
| **二重积分每年必有一道大题** | **11/11** | ✅ 全卷最稳定的一格,雷打不动 |
| **线代大题必落在"特征值/二次型"** | **11/11**(改革后 5/5) | ✅ **L1行列式、L2方程组已彻底退出大题**,只剩小题 |
| 多元微分每年一道 | 10/11(**2021缺席**) | ✅ 近乎必出 |
| 一元积分每年一道 | 10/11(**2022缺席**) | ✅ 近乎必出 |
| 微分方程"每年必出" | **9/11**(2018、**2025 缺席**) | ⚠ **教辅口径不准**:2025 刚缺席一次,降格为选择3+填空15(二阶齐次解衰减、全微分方程求特解) |
| 第21位是证明题 | 2022–2025 **连续4年** | ✅ 2021 尚未固定,2022 起锁死 |
| 极限连续进大题 | 2021 后 **0/4** | ⚠ **已退出大题**(2021 第17题是最后一次),现只在小题 |

**→ 三条考场结论**
1. **二重积分 + 特征值二次型 = 两格必得分**(约 23–24 分),是全卷性价比最高的两块,必须练到零失误。
2. **2025 提醒:微分方程不是"必出大题"**。它的真实地位是"高频但可缺席",缺席那年会以两道小题补偿——**别把它当保底,也别因它缺席一年就降权**(9/11 仍是主力)。
3. **第21位=证明题已连续4年**,且 2022/2025 两次都是**充要性**(不再是单向不等式)。这是近5年最清晰的单点趋势,见画像"证明题从单向证到充要刻画"。

### 选填强、大题弱的四道坎(能力 Gap,非知识 Gap)

选填熟练只证明**知识点识别**没问题;大题另考四种能力,任何一条不过关都会在 70 分里塌方:

1. **执行长度:3步 vs 15步。** 选填 3–5 步靠"看出来",大题 10–15 步靠"算到底"。典型塌方点:分部积分连着换元(2018解15)、部分分式拆分(2019解16)、直角坐标二重积分的大数计算(2013解17)。→ **限时全流程训练,不许跳步,算完代回验一个特殊值。**
2. **跨章串联:点 vs 线。** 大题几乎全是二合一/三合一——微分方程+旋转体(2010解18、2019解17、2020解18)、变限积分+微分方程(2018解16、2021解19)、偏导+微分方程(2015解18、2024解20)、几何条件+微分方程+最值三连(2001解八、2021解20、2023解17)。**第一问的输出就是第二问的输入**,选填练单点,大题考焊接。→ 对应本文件的 37 条缝合链。
3. **建模翻译:几何条件 → 微分方程(数二独有)。** 数二与数一数三差异最大、选填完全练不到的一环:切线截距 $Y=y-xy'$、法线与 $x$ 轴交点、曲边梯形面积 $\int$、弧长 $\int\sqrt{1+y'^2}\,dx$、曲率公式的正用与反用、做功/压力/冷却模型。**第一步翻译不出来,后面全白搭。**
4. **书写与分类讨论:会判断 vs 会论证。** 选填只需判真假,大题要写"设 $F(x)=\cdots$,验证 $F(a)=F(b)$,由罗尔定理…"的完整叙述;含参问题(二阶方程共振 1990/1994/1996、可对角化重根 2003/2004、方程组含参 1997/2004)必须**自己枚举所有情况**——选填时这些讨论被选项替你做了。→ 中值定理的经典辅助函数要熟到默写(见谁减谁 / 乘 $e^{kx}$ / 乘 $x$ 的幂)。

## 二、缝合演变链全谱(37条,每条=跨年证据+演变+考场反制)

> 注:链证据合成于2013补录前,2013年题目(见逐题地图)可作各链增量证据,不翻已有结论。

### 变限积分×无穷小阶比较(小题常青链)
- **证据链**:1999·选择二(2), 2001·选择二(2), 2004·选择7, 2011·解答15, 2020·选择1, 2021·选择1
- **演变**:1999年首次让两个变限积分比阶;2004扩成三个排序;2011进解答题、要求双侧极限定参数范围;2020-2021连续两年回归选择题固定化。被积函数从简单幂函数升级为需先做等价代换/复合处理才能定阶,但骨架三十年未变:变限积分是阶数的'包装纸'。
- **反制**:第一步对每个变限积分洛必达求导(或对被积函数做等价替换后直接积出),把每项的阶k明确写在旁边再比较;绝不凭整体感觉排序。

### 变限积分×函数性态判定(单调/极值/零点/奇偶/周期)
- **证据链**:1993·填空3, 1995·解答四, 2004·解答17, 2006·选择8, 2010·解答15, 2015·解答19, 2024·选择3, 2025·选择2, **2013·选择3**
- **演变**:早年(1993/1995)只问单调区间和最值这一层;2004缝周期性与值域、2006缝奇偶与间断;2010s缝零点个数;2024-2025连续两年小题化,且2025把极值点与拐点合并联判——判定的性质从一个变两个,载体始终是F(x)=∫f。
- **反制**:先写F'(x)=f(x)(含参上限用链式法则),所有性态问题一律回到F'的符号表;奇偶/周期用换元u=-t或u=t+T对积分直接验证。

### 积分方程(卷积型/含参)化微分方程
- **证据链**:1989·解答五, 2001·解答6, 2007·解答17, 2016·填空12, 2018·解答16, 2020·解答18
- **演变**:1989年卷积型∫f(x-t)dt换元后求导一次即得;2001/2007升级为上限含f(x)或反函数、需用反函数导数关系;2016转填空并要n阶导递推;2018需换元后连续求导两次;2020解出f后还要接旋转体体积——从'求f'单层缝合演化为'求f+用f'双层缝合。
- **反制**:被积函数含x先换元(u=x-t)或把x因子提出积分号,使x完全脱离被积函数,再对x求导;求导前先代x=0等特殊点抢初值。

### 变限积分嵌入求导载体(参数方程/隐函数/偏导)
- **证据链**:1996·解答三(3), 2003·解答4, 2005·选择11, 2009·填空9, 2021·填空14, 2022·选择4, 2025·选择1, 2025·填空14
- **演变**:1996/2003在解答题里求含变限积分的参数方程二阶导;2009降格为填空求切线;2005/2022向多元扩散(变限积分函数的高阶偏导);2021先二重积分换序再对变限积分求导;2025一年两题(选择缝隐函数偏导、填空缝参数式隐函数)——变限积分已成为一切求导题型的默认零件。
- **反制**:对整条等式/参数式两边同时求导,变限积分部分直接套牛顿-莱布尼茨,绝不先尝试把积分算出来。

### 极限式定义函数×间断点/可导性
- **证据链**:1998·解答三, 2001·解答4, 2004·填空1, 2005·选择7, 2015·选择2, 2024·选择1
- **演变**:1998/2001在解答题对幂指函数逐段求极限判间断;2004-2005转为小题并缝可导性(max型函数的不可导点);2015/2024稳定为选择题。二十余年考法不变、只换极限式:先由极限得到分段函数,再判衔接点的间断类型。
- **反制**:对含xⁿ或幂指结构的极限函数,先按|x|与1(或参数分界)分段写出f(x)的显式分段表达式;间断点只可能出现在分段衔接点,逐点算左右极限。

### 泰勒展开×极限:正向计算→反向拆信息
- **证据链**:1999·解答三, 2000·选择二(4), 2000·解答九, 2003·解答3, 2006·解答15, 2018·选择1, 2018·填空9, 2022·解答17, 2025·解答18, **2013·解答15**
- **演变**:1999-2006是正向:用泰勒算极限或由高阶无穷小定常数;2018起反向化:由极限值反推参数;2022/2025进一步由'极限存在'反推f(1),f'(1)或f(0),并要求按定义证可导——极限从求解目标变成了信息源,泰勒是拆包工具。
- **反制**:见'lim=有限值'先做信息拆解:分母趋0则分子必趋0,逐层剥出f(x₀)、f'(x₀);展开阶数取到与分母同阶为止,再多展一阶防抵消。

### 导数定义在分段点/特殊点的判定
- **证据链**:1990·选择二(5), 1999·选择二(1), 2004·解答16, 2015·选择3, 2019·解答15, 2020·解答16, 2024·选择2, 2025·选择7, **2013·选择2**
- **演变**:早年(1990/1999)判间断与0处可导(缝夹逼);2004函数方程延拓后在0处用定义定参;2015考f'在0处连续的参数范围(无穷小阶压制);2019/2020考分段点判定与导函数连续性;2024缝参数方程、2025缝绝对值差商——近年年年小题化,且专挑'差商极限存在≠可导'这类概念陷阱。
- **反制**:分段衔接点/极限定义点只许用lim[f(x)-f(x₀)]/(x-x₀)求导,先验连续再谈可导;判f'连续还要比较lim f'(x)与定义算出的f'(x₀)。

### 绝对值×可导性/分段积分
- **证据链**:1987·选择九(1), 1998·选择二(2), 1998·解答六, 2016·解答16, 2019·解答19, 2025·选择7
- **演变**:1987/1998考不可导点计数(看|x³-x|类因式零点的重数与变号);1998同年绝对值进反常积分要求分段;2016/2019进含参积分与分段面积级数;2025回到概念本源——差商含绝对值时能否推出可导,由计算题转为定义辨析题。
- **反制**:见|f(x)|先求零点并判每个零点处是否变号:变号零点是不可导嫌疑点;积分题第一步按零点拆区间脱绝对值,别带着绝对值硬算。

### 积分定义求和式极限
- **证据链**:2002·填空4, 2003·选择2, 2009·填空11, 2010·选择6, 2025·填空13
- **演变**:2002/2003标准n项和化∫₀¹;2009变形为'先算积分再取极限'的高频振荡型;2010扩到二重和式识别为二重积分;2025回归一元但缝瑕积分(xlnx在0端)——在'识别成积分'与'先积后限'两个方向上轮换出题。
- **反制**:见Σ先提1/n凑f(i/n)标准形;若n的位置不标准(如求lim n·aₙ),先把aₙ写成定积分表达式再乘n取极限。

### 单调极值分析×零点/根个数讨论
- **证据链**:1989·解答六, 2000·解答八, 2003·解答7, 2015·解答19, 2016·解答21, 2017·解答19, 2021·选择4
- **演变**:1989证超越方程根数、2003含参讨论交点个数是正向套路;2015-2017零点载体换成变限积分函数与原函数概念;2021方向反转——由零点个数反求参数范围。'正向数零点'到'反向定参'是本链近年的标志性变化。
- **反制**:求导列驻点→画单调性表→算各极值与端点/无穷远处的符号,零点数=符号改变次数;含参题先做参数分离,化为水平线与固定曲线的交点计数。

### 单调性/凸性×不等式与比大小
- **证据链**:1994·解答三(5), 1997·选择2, 2000·选择二(3), 2001·选择二(4), 2002·解答9, 2015·解答21, 2017·选择2, 2018·选择4, 2019·选择5, 2020·选择6, 2022·解答21, 2025·解答21
- **演变**:90s比较积分与矩形/梯形面积,靠几何直观;2000s构造商函数或辅助函数定号;2017-2019连续以'凸函数积分不等式'出选择题;2022/2025升级为充要性证明(凸性⇔切线位置⇔差商递增)——从'会用凸性'考到'会刻画凸性'。
- **反制**:比大小先试辅助函数求导定号(见f'g-fg'结构立即构造f/g);凸性题画一条弦一条切线,先从图上读出不等号方向再写证明。

### 中值定理多层串联证明(压轴证明题主链)
- **证据链**:1993·解答八, 1996·解答七, 1999·解答八, 2001·解答10, 2002·解答9, 2003·解答10, 2005·解答19, 2007·解答21, 2008·解答20, 2009·解答21, 2010·解答21, 2017·解答19, 2019·解答21, 2020·解答20, 2023·解答21, 2024·解答21, 2025·解答21, **2013·解答18**
- **演变**:90s是'介值/零点定理+罗尔/拉格朗日'两层定式;2000s加码为双中值、柯西三层、辅助函数构造,甚至要求证明定理本身(2008积分中值、2009拉格朗日);2017后泰勒展开成为主力(2019/2023/2024余项估计),2025转向充要性刻画——从'套定理'演化为'懂定理'。
- **反制**:数结论中ξ的个数与导数阶:一个ξ配一阶导→罗尔/拉格朗日;一个ξ配二阶以上→泰勒在中点或端点展开;两个ξ→区间对分各用一次中值。辅助函数从结论倒推:把ξ换回x,凑成某函数的全导数。

### 递推数列×经典不等式×单调有界
- **证据链**:1999·解答十, 2006·解答18, 2011·解答19, 2018·解答21, **2013·解答20**
- **演变**:1999用积分不等式压出单调与有界;2006缝1^∞型极限求值;2011/2018固化为'一条函数不等式(lnx≤x-1或e^x≥1+x)+单调有界准则'的双件套——不等式来源从积分估计变成泰勒截断,骨架未变。
- **反制**:先解x=f(x)猜出极限L,再拿L当界:证xₙ与L的大小关系→证单调;所需不等式几乎必是e^x≥1+x或ln(1+x)≤x的变体,先默写备用。

### 曲率作缝合件
- **证据链**:1998·解答十, 2001·解答5, 2009·选择5, 2016·选择5, 2018·填空12, 2019·选择6, 2024·填空11
- **演变**:1998用曲率建二阶微分方程(大题);2001曲率半径对弧长求导;2009之后全部小题化——缝凹凸性(2016)、缝参数方程(2018)、缝泰勒与相切充要条件(2019)、缝隐/反函数求导与曲率圆方程(2024)。曲率公式本身从不难,难度全在'先用别的工具把y′、y″求出来'。
- **反制**:先用题目给的载体(参数式/隐函数/反函数)把指定点的y′、y″求干净,最后一步才代K=|y″|/(1+y′²)^{3/2};要曲率圆再沿法线取距离R定圆心。

### 隐函数求导作载体
- **证据链**:1991·选择二(1), 1997·解答三(2), 2007·解答20, 2010·选择5, 2016·解答17, 2017·解答18, 2024·填空11, 2025·选择1, **2013·选择2**
- **演变**:1991/1997求切线与相切参数;2007缝链式二阶导;2010s缝极值判定(2016二元、2017一元),'驻点条件代入二阶求导式化简'成为固定考察;2024/2025缝曲率与变限积分——隐函数从考点本身退化为求导载体。
- **反制**:隐函数极值题:方程两边求导后令y′=0得驻点关系;再对求导式整体二阶求导并代入y′=0大幅化简。绝不尝试解出y(x)显式。
