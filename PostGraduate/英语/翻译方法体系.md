# 考研英语翻译方法体系（英译汉）

> 三层结构：① 中英文差异与中文语法（为什么要调整）→ ② 做题三步流程（怎么下手）→ ③ 映射规则与成分译法（每一块怎么落地）→ 附最终检查清单。

---

# 第一层 中英文差异与中文语法基础

## 1. 翻译 = 两套思维的切换

阅读只需从英文取意思；翻译多一步：**用中文重新组织**。"每个词都对、整句不像中文"就是没完成这一步。流程：先按英文结构确定谁做什么与逻辑关系 → 放下英文表面词序 → 按中文信息顺序、主谓关系和习惯重新组句。

## 2. 五组表达差异（是倾向，不是绝对属性）

| 维度 | 英文倾向 | 中文倾向 | 翻译动作 |
|---|---|---|---|
| 句长 | 长句、层层从属 | 短句、分步展开 | 拆句 |
| 词类 | 名词化、静态 | 动词化、动态 | 名词恢复成"谁做什么" |
| 主语 | 物/抽象概念常作主语 | 人/机构/具体对象更自然 | 按证据换主语（原文刻意隐藏施事时不能随便补人） |
| 衔接 | **形合**（连词、形态、从属结构显式标记） | **意合**（语序、语境、语义衔接） | 连词按清晰度取舍；因果/条件/让步不显化会歧义时必须补 |
| 指代 | 代词多 | 必要时**复现名词** | 有歧义就把代词换回名词 |

## 3. 时态、语态、逻辑的显化（增译的依据）

英语靠动词形态编码时间/完成/进行/被动；汉语靠时间词、体标记、语境、句式：
- `I have finished my work.` → 我**已经**完成了工作（完成态显化）
- `I was working.` → 我**正在**工作
- 逻辑关系与指代：可补"因为、所以、但是、这一点、这种做法"——**补出的内容必须能从原句结构推出**

## 4. 中文语法骨架

$$\text{主语}+\text{修饰/插入成分（俗称"废话"）}+\text{谓语}+\text{宾语}$$

- "废话"≠可删——指主干之间的修饰、限定、背景、插入说明，要识别功能并妥善安置
- 中文主语可以很长；多个谓语可**共享主语**、省略重复主语
- **动宾尽量靠近**：核心动词与宾语间不要隔过长成分（可读性策略，非无例外定律）

## 5. 逗号两侧关系（课程简化二分）

| 类型 | 判据 | 处理 |
|---|---|---|
| 分句 | 共享/省略同一主语，或只是时间地点等背景 | 逗号串联动作、背景前置为状语 |
| 从句 | 出现**新主语**，两侧有因果/条件/转折/让步 | 把逻辑关系表达清楚，必要时补连接词 |

看到逗号先问三件事：新动词的施事者是谁？与主句主语相同吗？表达什么逻辑关系？（英文分号在中文可处理为句号。）

## 6. 信息顺序调整

- **先叙事后评论**：英文常评论在前（`It's funny to play tennis.`）→ 中文"打网球很有趣"（事实先出）
- **先分后总 vs 先总后分**：英文先中心后展开；中文常先铺陈后总结——调序时不能削弱原文焦点
- **条件/原因前置**：英文后置 `if` 条件 → 中文"如果……那么……"（若后置更自然且无歧义也可保留）
- **时间地点前置**：形成"何时、何地、谁、做什么"
- 定语/状语角色可转换：后置定语→前置；过长定语→独立分句；介词短语→状语；抽象名词→动作表达。**顺序可调，修饰关系与否定范围不能乱**

# 第二层 做题三步流程（长句 = 任务分解）

```
第一步 断句
第二步 翻译
  ├─ 判断句子类型（逗号很多/多重定语从句 → 可能需"剥洋葱法"重组，考研中较少见）
  ├─ （可选）先总结结构：一个主句 + 几个从句 + 几个非谓语
  └─ 按具体规则翻译（★核心）
第三步 梳理逻辑结构、重新调整句序（可选但常有帮助）
```

## 断句的五类位置

| # | 位置 | 限定 |
|---:|---|---|
| 1 | 标点处 | 结构分析仍应明确分段 |
| 2 | 从句标志处 | 从句是相对独立结构 |
| 3 | 非谓语处 | 独立主格、现在/过去分词、不定式 |
| 4 | 介词短语处 | **最需条件判断**：属于动词整体/短语动词→不断；作定语→可不断；**作状语→断** |
| 5 | 主句/主语过长的边界 | 长主语结束处再断；长主语内部可能还含定语从句 |

断句检查顺序：标点 → 从句标志 → 非谓语 → 介词短语功能 → 长主语 → 复查每个单位是否仍是有意义结构（不破坏固定搭配）。

# 第三层 映射规则

核心不是词性对译，而是**功能映射**：

$$\text{英语形式}\to\text{语义与句法功能}\to\text{汉语成分}\to\text{自然汉语表达}$$

## 1. 英文侧：七类词性 + 三类结构

词性：名词、动词、形容词、副词、代词、介词、连词
结构：从句、介宾结构、非限定动词结构

| 英语形式 | 处理要点 |
|---|---|
| 名词（抽象/偏正） | 保留 / 偏正重组 / **动词化**（`the development of X`→"X 发展"）/ 过长拆句用"这一过程"承接 |
| 动词（弱动词/系表） | 找谓语短语整体含义选自然中文动词：`have dinner`→"吃饭"；保留进行/完成/被动信息 |
| 形容词、副词 | 定语状语可互换：`the America of [年份]` 可译"在[某年]，美国……" |
| 介词短语 | 可作定语或状语；可动词化：`with a pen`→"**用**笔" |
| 连词 | 连接成分或分句（≠介词）；按中文意合可省，逻辑含混必须保留 |
| 代词 | 服从指代清晰度，必要时重复名词 |
| 非限定动词 | 找逻辑主语 → 判断与主句的时间/原因/条件/伴随关系 → 短则作状语，长则拆分句；**动作不能漏** |

⚠ 一个简单分句围绕一个限定谓语；复合句每个从句各有限定谓语——长句按分句逐层找谓语。

## 2. 中文侧：句子成分译法（优先级：状语 > 定语 > 主语 > 谓语被动 > 其他）

| 成分 | 译法 |
|---|---|
| **状语**（出现最频繁） | 一般状语放主语后谓语前；时间地点可句首建场景；统摄全句的可前置；过长拆独立分句 |
| **主语/主语从句** | 中英主语可能不一致；长主语从句：先译成完整事实，再用**本位词**（"这、这一点、这种做法"）承接 + 谓语评价 |
| **定语从句** | 前置（短，"……的"）/ 后置（长、信息独立，另起分句）/ 句首展开（极长背景先译，主语最后出场）。经验阈值：约 8 词以内前置、以上后置（启发不是规则，以修饰关系清楚、不头重脚轻为准） |
| 同位语 | 破折号插入解释；或主谓化："Beijing, the capital of China"→"北京是中国的首都，它……" |
| 同位语从句 | 顶真承接：`a sign that China is rising`→"这是一个标志，标志着中国正在崛起"（或直接"这标志着……"） |
| 插入语 | 普通补充保留原位（逗号/破折号）；**观点来源提到句首**："某某认为，……"（保留"认为、可能、据说"的强度） |
| 谓语 | 重点是**被动语态**：视语境保留"被"、改主动或无标记表达——施事、受事、焦点不能变 |
| 宾语 | 相对简单；宾语从句先译"谁认为/据说"再逗号引出内容（⚠ `It is said`→"据说"；`It is believed/thought` 才是"人们认为"） |
| 本位词/外位语 | "其、该、这"承接前文；指代内容不能消失 |

## 3. 增译与减译（词可增减，意义不能）

- **增**：显化时体语态（已经/正在/了/被）、逻辑词（因为/但是/如果）、承接词（这一点）、并列宾语的不同谓语（`He wears a hat, a scarf and a coat.`→"他**戴着**帽子，**围着**围巾，**穿着**大衣"）
- **减**：冠词通常不逐字译；语境清楚的代词可省；形式性介词、连词可转换或省略
- 不可动的：否定、条件、程度、时间、数量、例外、比较对象、观点来源

# 附：最终检查清单（十步）

| # | 操作 | 完成标准 |
|---:|---|---|
| 1 | 按谓语、连接词断句 | 每块边界有依据 |
| 2 | 找主句与各块逻辑主语 | 每个动作都有主体 |
| 3 | 标词性、短语、从句功能 | 不只看表面词性 |
| 4 | 逐块初译（不熟练先打草稿） | 否定、数字、条件不丢 |
| 5 | 映射汉语成分 | 主干与修饰关系清楚 |
| 6 | 重排逻辑与信息顺序 | 条件、原因、背景位置自然 |
| 7 | 必要时拆句或动词化 | 不头重脚轻 |
| 8 | 补关联词、承接词、谓语 | 每处增译可解释 |
| 9 | 查**主谓、动宾、修饰**三轮搭配 | 无对象错配（如"把数据和人比较"）、无生硬修饰（如"方方正正地站着"应为"笔挺地站着"） |
| 10 | 回对原文 | 无漏译、无依据外增译、观点强度不变 |
